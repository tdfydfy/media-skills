# 生成指引（② 生成 HTML）

**读者：把 `脚本.json` 变成 `脚本.html` 的那一步。**
上游给的是「哪些字、哪种关系、第几秒」；视觉决定全在该风格的 `spec.md` 和 `template.html` 里。

> **在这一步，你是照抄工，不是设计师。**
> 你的活是"把已有的块搬到对的位置、换掉里面的字"。
> 一旦你开始想"这里是不是可以更炫一点"，产物就开始漂移了。

---

## 一、你在做什么

```
脚本.json  ──────────────►  脚本.html
（内容 + kind + 时间）        （1080×1440 透明画布 + 按秒进出的几个块）
```

一张透明画布上，几个素材点按时间进来、停 3~5s、压回去。产物里**没有声音、没有底**——口播和实拍在原片里，底由用户在剪辑时加。

`template.html` 是这一风格的总文件，它三块分工不同：

| 段 | 内容 | 你动不动 |
|---|---|---|
| `:root` + `.plate` + `.comp` + 零件 | 变量、承载板、三态、微件 | **不动** |
| `@keyframes` + `.comp.in/.out` | 动效名 → 实际动画 | **不动** |
| `<template id="kit">` | 样板间，每个 kind 一个真实例子 | **只读，抄它** |
| `<div id="track">` | 产物区 | **只改这里** |

## 二、动手前读什么

| 读 | 看哪 | 为什么 |
|---|---|---|
| 该风格 `spec.md` | 第五、六、八节 | 变体判别规则、硬约束、入场配方 |

## 三、六步

### 第 1 步 · 复制

把 `styles/<meta.style>/template.html` 整份复制成**与脚本同名**的 `.html`（`example/script.json` → `example/script.html`）。

### 第 2 步 · 清空产物区

删掉 `#track` 里现成的示例块，只留空的 `<div class="track" id="track">`。

### 第 3 步 · 逐点抄

按 `points` 的顺序，每个点做四件事：

1. 在样板间找 `<!-- kind: 该点的 kind -->` 那个块；**有变体的**（锚点写成 `kind: xxx | 说明`）按 `spec.md` 第五节的判别规则挑，规则没覆盖时用**没有变体后缀的那条**
2. 整块复制进 `#track`
3. **把 `<!-- kind: xxx -->` 这行锚点一起带过来** —— 校验和自查都靠它，别省略
4. 换内容 + 填时间（下面两张表）

### 第 4 步 · 换内容

`blocks` 数组的第 n 项 → 样板间里第 n 个位置。**数目对不上就删行，不许留样例文字。**

| `kind` | `blocks` | 抄样板间的哪块 | 怎么填 |
|---|---|---|---|
| `大数字` | `[{ value, caption }]` | `c-data` | 数字进 `data-to`，符号进 `data-prefix` / `data-suffix`（`70%+` → `data-to="70"` + 后缀 `%+`）；`.cap` 填 caption |
| `占比` | `[{ pct, caption }]` | `c-ring` | `.arc` 的 `data-grow` = pct/100；`.mid b` 的 `data-to` = pct、后缀 `%`；`.cap` 填 caption。`.mid span` 可删 |
| `数值比大小` | `[{ t, v }] × 2~4` | `c-bar` | 每行 `.lb span` = t、`.lb b` = v；`.fill` 的 `data-grow` = 本行数值 ÷ **最大那一行**的数值 |
| `趋势` | `[{ caption }]` | `c-line` | 只换 `.cap`。**折线形状固定用样板间那条，不按数据画**（脚本没给数据点，别编） |
| `进度` | `[{ pct, caption }]` | `c-prog` | `.hd span` 填 caption、`.hd b` 的 `data-to` = pct；`.fill` 的 `data-grow` = pct/100 |
| `数字对比` | `[{ t, v }, { t, v }]` | `c-vcmp` | 每侧 `b` 的 `data-to` = v、`span` = t。**数值大的一侧加 `.win`，另一侧加 `data-shrink=".84"`** |
| `转化` | `[{ t, v }, { arrow }, { t, v }]` | `c-flow` | 首尾两个 `.node`（`.t` = 第一个键、`.v` = 第二个键），`arrow` 进中间 `.arw span`，**末一个 `.node` 加 `.to`** |
| `对照` | `[{ label, text }, { label, text }]` | `c-cmp` / `c-vs` | 前者进 `.blk.a`（弱、划线），后者进 `.blk.b`（焦点）。**两侧各 ≤4 字且都不含数字才用 `c-vs`；含数字或更长一律 `c-cmp`（竖版默认）** |
| `三步递进` | `[{ t, v }] × 2~3` | `c-stack` | 每行 `.t` / `.v`，**逐行补 `style="--i:0"` `--i:1` `--i:2`** |
| `关键词 + 释义` | `[{ term, def }]` | `c-kw` + `c-note` | `.kw` = term，`.note` = def |
| `章节标记` | `[{ idx, title }]` | `c-step` | `.micro-idx` = idx（两位），`.title` = title |
| `引语` | `[{ text }]` | `c-quote` | `.tx` = text。`.by` 可删 |
| `清单` | `[{ item }] × 2~4` | `c-list` | 每项一行 `.row`，不要加序号 |

**可删的位**是样板间多带的一个说明位（`占比` 的 `.mid span`、`引语` 的 `.by`）——脚本没给对应的字就整行删掉，留着会出一个空口。

### 第 5 步 · 填时间

```html
<div class="comp bare" data-in="18.6" data-out="22.5" data-anim="EMBOSS-IN">
```

| 属性 | 填什么 |
|---|---|
| `data-in` | 该点的 `start`，**原片的绝对秒**，不加偏移 |
| `data-out` | 该点的 `end` |
| `data-anim` | **样板间里那个块写的是什么就是什么**，按 `spec.md` 第八节 |
| `data-out-anim` | 不用写，默认 `SINK-OUT` |

`data-in` / `data-out` 直接来自脚本，**唯一来源**。脚本改了时间，这里跟着改，别自己挪。

### 第 6 步 · 自检

- [ ] `#track` 里**只有**要用的块，样板间剩下的没跟过来
- [ ] 每个块上带着 `<!-- kind: xxx -->` 锚点，个数 = `points` 个数
- [ ] **没有任何样例文字残留在产物里**
- [ ] 动效名只用了 `EMBOSS-IN` / `PRESS-IN` / `QUOTE-IN`，**全片至少 3 种**（`spec.md` 第八节）
- [ ] `spec.md` 第六节的硬约束：板内凸起 ≤3、凹陷 ≤5、强调红一处、弱文字 ≥24px
- [ ] 跑校验：

```bash
node ivh-next/check.mjs ivh-next/example/script.json ivh-next/example/script.html
```

- [ ] 浏览器打开看：默认预览播一遍 → `?kit=1` 对比样板间 → `?t=18.6` 定格进场那一帧

## 四、你能定的 / 不能定的

| 你定 | 你不能定 |
|---|---|
| 抄哪一块、用哪个变体（按规则） | 新造一个组件 |
| 删掉多余的行、删掉可删的说明位 | 改色、改字号、改圆角、改影 |
| 文字里的断行、标点 | 改 `data-anim` 的名字 |
| 块的先后（就是 `points` 的顺序） | 「这里加个更炫的」 |

**想加新形态 → 先去 `spec.md` 第五节加一行、去 `template.html` 样板间加一个例子，再回来抄。**
两个文件改完，`check.mjs` 会替你确认对齐没对齐。

## 五、最常犯的五个错

1. **样例数字没换掉** —— 产物里留着 `37%` / `华东区`，脚本根本没这句
2. **填了相对时间** —— `data-in` 写成"第 5 秒"，实际该是原片的绝对秒
3. **把整个样板间搬进 `#track`** —— 产物区变成一个演示页
4. **加了 `border` 或深色降级** —— 这套语言只有柔影和承载板，`spec.md` 第二节写死了
5. **自己给数字编折线** —— `趋势` 的线是同一条，只换 caption
