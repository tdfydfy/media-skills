# 生成指引（② 生成 HTML）

**读者：把 `脚本.json` 变成 `脚本.html` 的那一步。**
上游给的是「哪些字、哪种关系、第几秒」；视觉决定全在该风格的 `spec.md` 和 `template.html` 里。

> **在这一步，你是照抄工，不是设计师。**
> 你的活是"把已有的块搬到对的位置、换掉里面的字"。
> 一旦你开始想"这里是不是可以更炫一点"，产物就开始漂移了。

---

## 一、你在做什么

```
脚本.json  ──────────────►  脚本.html
（内容 + kind + 时间）        （1080×1440 透明画布 + 按秒进出的几个块）
```

一张透明画布上，几个素材点按时间进来、停 3~5s、压回去。产物里**没有声音、没有底**——口播和实拍在原片里，底由用户在剪辑时加。

`template.html` 是这一风格的总文件，它三块分工不同：

| 段 | 内容 | 你动不动 |
|---|---|---|
| `:root` / `.comp` 及其 `::before` / 壳 / 零件 | 变量、壳、微件 | **不动** |
| `@keyframes` + `.comp.in/.out` | 动效名 → 实际动画 | **不动** |
| `const CONFIG = {…}` | ④ 渲染器靠它认出「3:4 透明素材」 | **不动，删了出不了片** |
| `<template id="kit">` | 样板间，每个 kind 一个真实例子 | **只读，抄它** |
| `<div id="track">` | 产物区 | **只改这里** |

## 二、动手前读什么

| 读 | 看哪 | 为什么 |
|---|---|---|
| 该风格 `spec.md` | 第五、六、八节 | 变体判别规则、硬约束、入场配方 |
| 该风格 `template.html` | 只要 `<template id="kit">` | 抄作业的对象 |

| 脚本 `points[n].form` | 每个点一行 | 这是 ① 替你定的**壳**（白话名），你在动手前换算成类名 |

**不要读 `extract.md`。** 那是 ① 的活，你手上的 `kind` 和 `form` 已经是结论。

## 三、七步

### 第 1 步 · 复制

把 `styles/<meta.style>/template.html` 整份复制成**与脚本同名**的 `.html`（`example/script.json` → `example/script.html`）。

### 第 2 步 · 清空产物区

删掉 `#track` 里现成的示例块，只留空的 `<div class="track" id="track">`。

### 第 3 步 · 换壳

`points[n].form` 是 ① 给的白话名，先换算成**壳类名**（写在 `.pnl` 上）：

| 白话名 | 类名 |
|---|---|
| `带底` | `frame` |
| `折叠` | `fold` |
| `亮条` | `bar` |
| `括标` | `bracket` |
| `无壳` | `bare` |

每档壳长什么样、什么时候用，见该风格 `spec.md` 第五节。
**同一个 kind 换壳就是换一个长相，内容一个字都不用改**
—— 全片只用一个壳，等于没设计。

### 第 4 步 · 逐点抄

按 `points` 的顺序，每个点做四件事：

1. 在样板间找 `<!-- kind: 该点的 kind -->` 那个块；**有变体的**（锚点写成 `kind: xxx | 说明`）按 `spec.md` 第五节的判别规则挑，规则没覆盖时用**没有变体后缀的那条**
2. 整块复制进 `#track`
3. **把 `<!-- kind: xxx -->` 这行锚点一起带过来** —— 校验和自查都靠它，别省略
4. 换内容 + 填时间（下面两张表）

### 第 5 步 · 换内容

`blocks` 数组的第 n 项 → 样板间里第 n 个位置。**数目对不上就删行，不许留样例文字。**

各风格的类名不一样，**这份文件不复述** —— 打开那个 kind 的例子，对号入座：

| 你手上 | 例子里的什么 |
|---|---|
| `blocks[n]` 的每个键 | 一个元素（`.t` / `.v` / `.lb` / `.tx` / `.kw` / `.def` / `.item` …） |
| 数值 | `data-to`（纯数字）+ `data-prefix` / `data-suffix`（符号）。`70%+` → `data-to="70"` + 后缀 `%+` |
| 柱 / 环 / 进度的长度 | `data-grow`，填 0~1 的比例 |
| 多行块（清单 / 三步递进 / 数值比大小） | 每行补 `style="--i:0"` `--i:1` `--i:2` —— **错峰靠它，不补就是所有行一起蹦出来** |
| `目录` 的行 | `blocks` 一条 = `.row` 一行，**每行都要 `style="--i:n"`** —— 逐条点亮全靠它，漏了就是整块端上来 |
| `目录` 的 `cur` | 序号 **小于** `cur` 的行加 `.done`、**等于**的加 `.cur`；**片头那一遍脚本不给 `cur`，一个都不加** |
| `关键词` | `word` → 只有 `.w` 那一个元素。别配释义、别配数字 |
| 顺序 | `kind` 决定谁是焦点：`对照` 的**后一项**是亮的那行，`转化` 的**末一个节点**加 `.to` |
| 可删的位 | 脚本没给对应的字就**整行删掉**（引语的 `by` 最常见），留着会出一个空口 |

**`趋势` 的图形形状是固定的**：脚本不给数据点，折线/柱形的样子照抄样板间那条，**不许自己编**。

### 第 6 步 · 填时间

```html
<div class="comp bare" data-in="18.6" data-out="22.5" data-anim="EMBOSS-IN">
```

| 属性 | 填什么 |
|---|---|
| `data-in` | 该点的 `start`，**原片的绝对秒**，不加偏移 |
| `data-out` | 该点的 `end` |
| `data-anim` | 按 `spec.md` 第八节的默认配方给。**同一个 kind 出现多次时按那一节轮换**，相邻两点不许同入场 |
| `data-out-anim` | 不用写，默认 `SINK-OUT` |

`data-in` / `data-out` 直接来自脚本，**唯一来源**。脚本改了时间，这里跟着改，别自己挪。

### 第 7 步 · 自检

- [ ] `#track` 里**只有**要用的块，样板间剩下的没跟过来
- [ ] 每个块上带着 `<!-- kind: xxx -->` 锚点，个数 = `points` 个数
- [ ] `目录` 块里**每一行都有 `--i`**，而且它在 `#track` 里的位置和脚本里的一致（片头那遍必须是最前面）
- [ ] 每个 `目录` 块的 `cur` 已换算成 `.done` / `.cur` 类 —— **片头那遍一个都不加**
- [ ] **没有任何样例文字残留在产物里**
- [ ] 动效名全在本风格 `spec.md` 第八节列的那几个里，**全片至少 3 种、相邻两点不同**
- [ ] 相邻两点的壳不同；本风格五档壳全片都出现过
- [ ] `spec.md` 第六节的硬约束逐条过一遍
- [ ] 跑校验：

```bash
node ivh-next/check.mjs ivh-next/example/script.json ivh-next/example/script.html
```

- [ ] 浏览器打开看：`?view=1` 播一遍 → `?kit=1` 对比样板间 → `?view=1&t=18.6` 定格
- [ ] **不加查询参数打开过一次** —— 那才是出片状态：全透明、缩放 1、没有播放条

## 四、你能定的 / 不能定的

| 你定 | 你不能定 |
|---|---|
| 抄哪一块、用哪个壳（就是脚本里的 `form`） | 新造一个组件、自创一个壳类名 |
| 删掉多余的行、删掉可删的说明位 | 改色、改字号、改圆角、改影 |
| 文字里的断行、标点 | 改 `data-anim` 的名字 |
| 块的先后（就是 `points` 的顺序） | 「这里加个更炫的」 |

**想加新形态 → 先去 `spec.md` 第五节加一行、去 `template.html` 样板间加一个例子，再回来抄。**
两个文件改完，`check.mjs` 会替你确认对齐没对齐。

## 五、最常犯的七个错

1. **样例数字没换掉** —— 产物里留着 `37%` / `华东区`，脚本根本没这句
2. **填了相对时间** —— `data-in` 写成"第 5 秒"，实际该是原片的绝对秒
3. **把整个样板间搬进 `#track`** —— 产物区变成一个演示页
4. **自己改样式** —— 加 `border`、改字号、改圆角、改影。壳和零件都在 `spec.md` 里写死了，改完就漂移
5. **自己给数字编折线** —— `趋势` 的线是同一条，只换 caption
6. **全片一种壳** —— 21 个点全是 `frame`，看得人眼睛疼。换壳是这套体系里最便宜的多样性
7. **`目录` 没补 `--i`** —— 一整块"啪"地端上来。逐条点亮就靠这一个属性，补了它才叫"分点呈现"
