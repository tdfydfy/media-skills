# 提取指引

这份共用，不含视觉决定。只做四件事：全片分几章、挑哪节、压成什么字、这是哪种关系。形式在风格 `spec.md` 里，两份文件唯一对接点是 `kind` 白话名。

读者：写脚本那一步。

---

## 一、先读全篇：章 → 节 → 句

通读全片，按**内容**整理出章、节、句。看不到画面时，就从内容上区分。

- **章**：一系列相关的内容，依次展开。全片 3~6 章，每章标题 ≤8 字，写话题。写进 `meta.outline`。
- **节**：一个具体的知识点或信息点。可能由一句台词讲清，也可能跨多句，要整体看。
- **句**：台词的切分，用来定位时间。节才是卡片的内容单位。

通常每一两句话会有一个小重点值得强调展示；有就做，不强求。

```json
"outline": [
  { "idx": "01", "title": "渠道结构变化", "start": 12.0, "end": 48.5 },
  { "idx": "02", "title": "一线为什么见顶", "start": 48.5, "end": 96.0 },
  { "idx": "03", "title": "三四线怎么接", "start": 96.0, "end": 137.0 }
]
```

章边界跟着**话题**走，不跟着句子走。少于 3 章说明还没读出结构，多于 6 章说明在切句子。

**先分章，再挑句。** `目录` 要报的章节名、`章节标记` 要报的位置、`关键词` 要认的锚，全都从这张表来；先挑句子，这三样都只能临时编，编出来彼此对不上。

---

## 二、全片目录：报章

**片头必给一次全片目录**，条目 = `meta.outline` 整张表，让观众先知道片子去哪儿。

局部提纲：口播自己数出几条，且那几条散在后面几十秒里，可在概括句后给一次 `目录`。条目写那几条自己的名字，3~4 条最舒服，最多 6 条，≤8 字。同句列完，用 `清单`。

`章节标记` 是逐条走到时各报一次位置，只报一个位置。

概括句 = 说话人自己把下面几条数出来的那一句（"主要看三个方面" / "三个核心逻辑" / "分两块讲"），句子里要有一个数量词。**只在他数了数、且那几条收得晚的时候才做**；自然语言讲了几个点、没有那句概括，就不做——替观众总结是加戏。

---

## 三、信息卡片：按节策划

每个节策划一张或一组信息卡片。先看这个节整体在讲什么，再看其中哪句提供抓手。

- 卡片落在节的口播上：结构、目录先给架子；数值与口播同步出现。
- 停留 3~5s；多行按行算，每行约 1.5~2s。
- 相邻卡片留 ≥1.5s 空档，让实拍主体露出来。点与点不重叠。
- 最后一点盖到片尾，距音轨结束不超过 6s。
- 密度按内容：有抓手就出，没内容不硬凑。时间码来自音轨。

**宁密勿稀。** 一条 137s 的口播出 20~30 个点是正常的；会变成"第二块屏"的是**每张卡都很满**，不是卡多。每张卡留白，卡与卡之间留空档。空档超过 8s 就说明漏了点。

---

## 四、一张表：抓手 → kind → 画面 → 屏幕字

抓句子、压屏幕字、认关系是一个整体。读到节里的抓手，定 `kind`，再按画面承担压屏幕字。

| 口播里的抓手 / 信号 | `kind` | 画面承担 | 屏幕字方向 |
|---|---|---|---|
| 从 A 变成 B | `转化` | 方向 | A → B |
| 不是 A，是 B | `对照` | 对立 | A vs B |
| 第一…第二…第三 | `三步递进` | 顺序 | 1 2 3 |
| 涨了 37% | `大数字` | 单一数值 + 归因 | 37% + 原因 |
| 其中三线占一半 | `占比` | 部分与整体 | 三线 50% |
| 从 2023 到 2026 一路走高 | `趋势` | 变化 | 2023→2026 上升 |
| A 比 B 高 | `数值比大小` | 量差 | A 40% / B 70% |
| 所谓 X 就是 Y | `关键词 + 释义` | 定义 | X = Y |
| 当下要聚焦的词 | `关键词` | 焦点 | 词 |
| 全片目录 / 局部提纲 / 跨章节要点 | `目录` | 全局位置 | 章列表 |
| 接下来讲第二点 | `章节标记` | 位置 | 02 标题 |
| 已完成六成 | `进度` | 完成度 | 60% |
| 金句、结论 | `引语` | 分量 | 金句 |
| 三个原因：… | `清单` | 并列 | 原因 1 / 2 / 3 |
| A 组和 B 组差多少 | `数字对比` | 落差 | A vs B 差 X |

**压屏幕字四步：**

1. **抓**：节里可量化或关键的信息：数字、时间、对比、代价、动作、判断。
2. **论点**：这些信息说明什么？或者强调什么？写成一句带因果的话。
3. **主张**：这句话的反面成立吗？有人反对，才是主张。
4. **屏幕字**：一行小标题 + 2~4 个信息块。不写主语、连接词，但信息不砍，关上声音也看得懂。

压是去掉主语、连接词、语气词；砍是删信息。
"客户明年 8 月结婚，没有替代方案"压成"有风险"就是砍。观众要细节。

`关键词` 是当下聚焦，只提醒"此刻重点是它"，不要求全片核心。要解释词义，用 `关键词 + 释义`。

## 五、交付：脚本 JSON

```json
{
  "meta": {
    "style": "soft-relief",
    "title": "渠道下沉带来的结构性增长",
    "ratio": "3:4",
    "duration": 137.0,
    "contentType": "data",
    "outline": [
      { "idx": "01", "title": "渠道结构变化", "start": 12.0, "end": 48.5 },
      { "idx": "02", "title": "一线为什么见顶", "start": 48.5, "end": 96.0 },
      { "idx": "03", "title": "三四线怎么接", "start": 96.0, "end": 137.0 }
    ]
  },
  "voiceover": [
    { "i": 1, "start": 0.0, "end": 3.8, "text": "我们先看一组反常的数据。" }
  ],
  "points": [
    {
      "i": 1,
      "kind": "目录",
      "form": "凸起",
      "kick": "这条片子的三段",
      "start": 0.6,
      "end": 10.4,
      "blocks": [
        { "idx": "01", "title": "渠道结构变化" },
        { "idx": "02", "title": "一线为什么见顶" },
        { "idx": "03", "title": "三四线怎么接" }
      ]
    },
    {
      "i": 2,
      "kind": "章节标记",
      "form": "凹陷",
      "kick": "第一章",
      "start": 12.0,
      "end": 15.6,
      "blocks": [{ "idx": "01", "title": "渠道结构变化" }]
    },
    {
      "i": 3,
      "kind": "转化",
      "form": "凸起",
      "kick": "一线到三四线",
      "start": 12.6,
      "end": 16.8,
      "blocks": [
        { "t": "一线城市", "v": "40%" },
        { "arrow": "渠道下沉" },
        { "t": "三四线", "v": "70%+" }
      ]
    },
    {
      "i": 4,
      "kind": "关键词",
      "form": "无板",
      "kick": "核心词",
      "start": 50.2,
      "end": 54.0,
      "blocks": [{ "word": "渠道下沉" }]
    }
  ]
}
```

- `points` 对应节卡片。`meta.outline` 对应章。`voiceover` 对应句。
- `blocks` 的长度和键由 `kind` 决定，每个 `kind` 要什么写在风格 `spec.md`。
- `kick` 是卡的小标题，每张卡都要有，≤12 字，写"这卡在讲什么"。
- `form` 用白话名，不写类名。该风格有哪几档写在风格 `spec.md`。相邻点尽量换 `form`。
- `目录` 片头那遍省略 `cur`，报整张表；局部提纲给 `cur`，值是这几条自己的 `idx`。同一条逻辑再报，只换 `cur`。
- `meta.contentType` 决定密度档：`data` 8~12 / `narrative` 6~10 / `drama` 3~5 / `opinion` 10~14
  （个/60s，往上沿走。`目录` 不计入，`章节标记` 算）。
- `meta.style` 决定读哪份 `spec.md`；`meta.ratio` 恒为 `3:4`。再给一份同名 `.md` 给人看。

## 六、自检

- [ ] 先分章，3~6 章，`title` 是话题，≤8 字。
- [ ] 每章含节；节是具体信息点，可能跨多句，整体看。
- [ ] 片头有全片目录，条目与 `meta.outline` 逐条一致，且比第一个内容点早。
- [ ] 口播里每句"我讲三个方面"式概括句，都已配上 `目录`；被概括句点名的并列几条，没有替它总结成提纲。
- [ ] `章节标记` 的 `idx` / `title` 在 `meta.outline` 里有对应项。
- [ ] 每张卡片指得回一个节，时间贴着该节口播。
- [ ] 每个点承担一个关系：对照 / 流向 / 递进 / 占比。`引语` / `章节标记` / `目录` / `关键词` 例外。
- [ ] `kind` 从第四节表里挑。
- [ ] `关键词` 是当下聚焦，按需出现。
- [ ] 数值与口播同步，不提前剧透；结构先给架子。
- [ ] 停留 ≥3s，相邻空档 ≥1.5s，点与点不重叠。
- [ ] 密度按内容来，有抓手就出，没内容就跳过。
- [ ] 时间码来自音轨，不是估的。
