## 10 个点

### 点 1 · `目录` · 0.2 → 5.0s（停 4.8s）
> 口播：今天讲一个跟直觉相反的结论。／先看第一部分，渠道结构发生了什么变化。

```
01  渠道结构变化
02  投放与复购口径
03  走势与结论
```

逐条落下来才是一份行程，整块端上来只是一张图。

### 点 2 · `章节标记` · 6.6 → 9.6s（停 3.0s）

```

```

### 点 3 · `大数字` · 11.2 → 15.0s（停 3.8s）
> 口播：所有增量里，三四线贡献了百分之五十四。

```
        54%
   增量贡献 · 三四线
```
只有一个数字，但带归因（谁贡献的）——**归因槽就是它跟"纯字幕卡"的区别**。数字后置 +0.3s。

---

### 点 4 · `转化` · 18.6 → 22.5s（停 3.9s）
> 口播：过去一年，一线从四成掉到三四线七成以上。

```
[ 一线城市   40% ]
        ↓ 渠道下沉
[ 三四线     70%+ ]   ← 焦点
```
口播里有方向（"掉到"），所以是**流向**不是对照。

---

### 点 5 · `数值比大小` · 25.1 → 29.0s（停 3.9s）
> 口播：三线及以下占五成四，二线三成一，一线只剩一成五。

```
三线及以下  ████████████ 54%
二线        ███████      31%
一线        ███          15%
```
三个数各有对照对象，是**量差**，不是三个孤立的数字。

### 点 6 · `对照` · 32.6 → 36.5s（停 3.9s）

```
今年  37%      ← 焦点
```
两块对等、没有方向 → 对照。竖版走 `c-cmp`（含数字，不走 `c-vs`）。
