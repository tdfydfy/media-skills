## 9 个点

### 点 1 · `章节标记` · 4.0 → 7.5s（停 3.5s）
> 口播：先看第二部分，渠道结构发生了什么变化。

```
[02]  渠道结构变化
```
结构 / 预告类，**入点在句首**（原片明说了"第二部分"）。

---

### 点 2 · `大数字` · 11.1 → 15.0s（停 3.9s）
> 口播：所有增量里，三四线贡献了百分之五十四。

```
        54%
   增量贡献 · 三四线
```
只有一个数字，但带归因（谁贡献的）——**归因槽就是它跟"纯字幕卡"的区别**。数字后置 +0.3s。

---

### 点 3 · `转化` · 18.6 → 22.5s（停 3.9s）
> 口播：过去一年，一线从四成掉到三四线七成以上。

```
[ 一线城市   40% ]
        ↓ 渠道下沉
[ 三四线     70%+ ]   ← 焦点
```
口播里有方向（"掉到"），所以是**流向**不是对照。

---

### 点 4 · `数值比大小` · 25.1 → 29.0s（停 3.9s）
> 口播：三线及以下占五成四，二线三成一，一线只剩一成五。

```
三线及以下  ████████████ 54%
二线        ███████      31%
一线        ███          15%
```
三个数各有对照对象，是**量差**，不是三个孤立的数字。

---

### 点 5 · `对照` · 32.6 → 36.5s（停 3.9s）
> 口播：去年是百分之十二，今年翻到了百分之三十七。

```
去年  12%      ← 划掉
─────────
今年  37%      ← 焦点
```
两块对等、没有方向 → 对照。竖版走 `c-cmp`（含数字，不走 `c-vs`）。

---

### 点 6 · `占比` · 39.1 → 43.0s（停 3.9s）
> 口播：三四线的复购占到整体的六成二。

```
    ╭─────╮
    │ 62% │
    ╰─────╯
  三四线复购占比
```
部分与整体 → 占比，不是大数字。

---

### 点 7 · `趋势` · 46.6 → 50.5s（停 3.9s）
> 口播：三四线渗透率从二零二三年到二零二六年一路走高。

```
      ╱
   ╱╲╱
 ─────────────
 2023 → 2026 三四线渗透率
```
变化 → 趋势。**折线形状固定**，脚本没给数据点，不编。

---

### 点 8 · `清单` · 53.1 → 57.0s（停 3.9s）
> 口播：降低理解成本，建立信息层级，提供视觉锚点。

```
降低理解成本
建立信息层级
提供视觉锚点
```
并列三条、无先后 → 清单（不是 `三步递进`）。

---

### 点 9 · `引语` · 59.0 → 62.4s（停 3.4s）
> 口播：动效不是装饰，是把声音里看不见的结构，翻译成眼睛能抓住的形状。
