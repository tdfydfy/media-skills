# 霓虹终端 · Neon Terminal — 透明素材

> 底透空，元素自己发光。**亮 = 在场，灭 = 缺席。**
>
> neon / hard / 一块搁在画面上的屏

**谁读这份：**

- **写脚本的人** —— 只读第五节的表（白话名 → 画成什么、容量）和第六节的硬约束。**永远不要写类名。**
- **生成 HTML 的人** —— 读第三、五、八节，然后去 `template.html` 的样板间照抄。

---

## 一、画幅与落位

```
1080 × 1440（3:4）        全透明，没有承载板
┌──────────────────────┐
│                      │
│    ╔════════════╗    │  ← 元素自带半透明暗底
│    ║  发光组件  ║    │     rgba(4,12,8,.78) + 1px 亮边
│    ╚════════════╝    │
│                      │
└──────────────────────┘
```

**没有承载板。** 每个点自己决定要不要那层半透明暗底 —— **有底读起来稳，没底读起来冲，两种都要有**。五档壳见第五节。

不加底的那两档（`bare` / `bracket`）里，**荧光绿只留给线和括标，字一律近白**——
绿色在浅色实拍上就是读不清。可读性靠 `.pnl.bare *,.pnl.bracket *` 上的暗描边：

```css
text-shadow: 0 0 4px rgba(2,8,5,.95), 0 3px 16px rgba(2,8,5,.92), 0 0 44px rgba(2,8,5,.72);
```

**这是"不加底也读得出来"的唯一保证，别删。** 数字 / 词条 / 引语再叠一层绿光做身份。

正文用近白 `#EAFFF2`。**不要拿荧光绿当正文字色**——绿是发光，不是颜色；整段绿字在浅色实拍上会糊成一片。

| 落位 | 类 | 谁用 |
|---|---|---|
| 中央 | `pos-c` | 默认。数字、图表、清单、词条 |
| 左上 | `pos-tl` | `章节标记` |
| 下三分之一 | `pos-b` | `进度`、`引语` |

**一个点一个落位。** 同一时刻只有一组元素。

## 二、发光与层级

**这套语言里没有影子。层级靠亮 / 灭。**

| 级 | 形态 | 用于 |
|---|---|---|
| L2 亮 | 荧光绿 `1px` 边 + 外发光 + 深绿实底 | 焦点、结论、当前项 |
| L1 半亮 | 青 `1px` 边，**无发光** | 对照里的次项 |
| L0 灭 | 暗底 + `1px dashed` 边 + 次色字 | 缺席、旧状态、问题 |

**灰在这套里读作"坏掉了"，不读作"次要"。** 要表示次要就用 L0 灭。

边框一律 `1px` / `1px dashed`。**这是与柔面凸凹最大的区别**：那套禁止 border，这套全靠 border。

**扫描线**是材质，不是内容——加在面板底上，**永不加在文字上**：

```css
background-image: repeating-linear-gradient(
  180deg, rgba(57,255,106,.07) 0 1px, transparent 1px 4px);
```

**四角括标**：L2 的面板上加左上、右下两个 L 形角标，`18px` 边、`2px` 粗。这是本套唯一的"装饰"，用来把面板读成一块屏。

## 三、色彩

| 名 | 值 | 角色 | 配比 |
|---|---|---|---|
| 面板底 | `rgba(4,12,8,.82)`／`.52` | 有底壳的底 | **只给有底的三档壳**（`frame` / `fold` / `bar`），无底壳不用 |
| 荧光绿 | `#39FF6A` | 焦点、亮态、线 | **≤15%** |
| 深绿 | `#0A2A18` | 亮块内部填充 | — |
| 青 | `#2BE7FF` | 数据次维 | **≤8%** |
| 洋红 | `#FF3D8B` | 警示、坏结果 | **≤3%** |
| 正文 | `#EAFFF2` | 主张与文字 | — |
| 次文 | `#7FA894` | 说明、单位、坐标轴 | — |

**绿是唯一的主导。** 一块板里青最多一处、洋红最多一处，**两个不同时出现**。

发光统一用 `text-shadow` / `box-shadow`，模糊半径 `10px`，透明度 `.5`：

```css
box-shadow: 0 0 0 1px #39FF6A, 0 0 18px rgba(57,255,106,.5), inset 0 0 22px rgba(57,255,106,.10);
```

## 四、字体

中文 `PingFang SC / Microsoft YaHei`；**数字与英文一律等宽**（`ui-monospace, "JetBrains Mono", Consolas`），字距 `0`——它们要一起跳。

| 用途 | 字号 | 字重 | 字距 |
|---|---|---|---|
| 巨数字 | 190 | 700 | 0 |
| 大数字 | 132 | 700 | 0 |
| 章节序号 | 132 | 700 | 0（描边空心） |
| 标题 | 72 | 700 | .01em |
| 词条 | 84 | 700 | .02em |
| 正文 | 36 | 400 | .01em |
| 标签 | 26 | 400 | .12em |

**字重只用 400 和 700。** 标签用大写英文间距（`.12em`）读作"仪表标签"，中文不受影响。

## 五、白话名 → 画成什么（核心表）

`kind` 从 `../extract.md` 第四节来。**写脚本只用第一列和最后一列。**

| `kind` | 画成什么 | 类名 | `blocks` 形状 | 容量 |
|---|---|---|---|---|
| `大数字` | 等宽巨字 + 上方标签 + 下方刻度条 | `c-huge` | `[{ value, caption }]` | 归因 ≤12 字 |
| `占比` | 圆环图，底环 L0 / 进度环 L2 | `c-donut` | `[{ pct, caption }]` | 说明 ≤10 字 |
| `数值比大小` | 每行：标签 + 水平柱 + 数值 | `c-bars` | `[{ t, v }] × 2~4` | 标签 ≤8 字 |
| `趋势` | 折线图，暗网格 + 发光折线 | `c-trend` | `[{ caption }]` | 说明 ≤14 字 |
| `进度` | 20 格刻度条 + 百分比 | `c-meter` | `[{ pct, caption }]` | 说明 ≤10 字 |
| `数字对比` | 两个巨字并列，一灭一亮 | `c-duel` | `[{ t, v }, { t, v }]` | 每侧 ≤8 字 |
| `转化` | 上块 → 发光连线 → 下块 | `c-flow` | `[{ t, v }, { arrow }, { t, v }]` | 关系标签 ≤8 字 |
| `对照` | 上灭下亮两行 | `c-vs` | `[{ label, text }, { label, text }]` | label ≤5 字，text ≤12 字 |
| `三步递进` | 编号节点竖列，逐个点亮 | `c-steps` | `[{ t, v }] × 2~3` | 每级 ≤8 字 |
| `关键词 + 释义` | 大号荧光词 + 打字机释义 | `c-term` | `[{ term, def }]` | 词 ≤10 字，释义 ≤30 字 |
| `章节标记` | 左上：空心大序号 + 亮条 + 标题 | `c-chapter` | `[{ idx, title }]` | 标题 ≤14 字 |
| `引语` | 方括号括标里的引文，落下方 | `c-quote` | `[{ text, by? }]` | text ≤34 字，by ≤16 字 |
| `清单` | 每行 `▸` + 文字 + 行尾虚线 | `c-log` | `[{ item }] × 2~4` | 每行 ≤16 字 |

### 每张卡都带一行小标题（`kick`）

每个点在 `blocks` 之外再写一个 `kick`（≤12 字），转成样板间里的 `.kick`：

    <div class="kick"><i class="tick"></i><span class="tx">对话到建议</span></div>

**它不是标题，是这张卡的"眉"。** 作用有三个：告诉观众这卡在讲什么、把大小字拉开层次、
给那根会生长出来的短横当落点。

- 横线先长出来，标签再滑进来——**这条动作是这套的招牌，别改**
- `kick` 写"这卡在讲什么"，`blocks` 写"具体是什么"。**两个不许重复**
  （✗ kick「业务闭环」+ term「业务闭环」；✓ kick「定义」+ term「业务闭环」）
- 一块板上**只有一个 kick**，放在最上面

**没有 kick 的信息卡 = 一屏字。** 这条是硬要求，不是建议。

### 五档壳（脚本只给白话名，类名在这一步才换算）

壳写在 `.pnl` 上。**同一个 `kind` 换壳 = 换一个长相，内容一个字都不用改。**

| 白话名 | 类名 | 长什么样 | 谁用 |
|---|---|---|---|
| `带底` | `frame` | 半透明暗底 + `1px` 亮边 + 左上/右下四角括标 | 要压住实拍的内容：图表、四行清单、章节 |
| `折叠` | `fold` | 同 `frame`，配合 `FOLD-IN` 沿中缝展开 | 表达"展开 / 对立"：`转化`、`对照` |
| `亮条` | `bar` | 只有左边一条 `4px` 亮条 + 半透明渐变底，无边框无括标 | 清单、进度、并列项 |
| `括标` | `bracket` | **无底**，只有两只四角括标 | 标题、金句 —— 实拍直接露出来 |
| `无壳` | `bare` | **什么都没有**，字自己发光 | 巨数字、词条 |

**规则：**

- 脚本的每个点写一个白话名（`points[n].form`），生成 HTML 时才换算成上面的类名。
- **相邻两点不许同壳，也不许同入场。** 同一个 `kind` 连着出现时，靠换壳 + 换入场拉开。
- 有底的三档和无底的两档**大约各占一半**。整片只会 `frame` = 满屏绿框，等于没设计。
- **不加底不是省事，是另一种强调。** 实拍那一段最干净的时候才配无壳；实拍花的时候加底。

### 表里写死的判别规则

**别让生成 HTML 的那一环临场发挥**——同一份脚本跑两次必须长得一样。

| 情况 | 用哪个 |
|---|---|
| `对照` | 一律 `c-vs`（上灭下亮）——"亮"这个动作本身就是结论 |
| `数值比大小`，2~4 行 | `c-bars` |
| `数值比大小`，5 行以上 | 拆成两个点，或改 `c-log` |
| `趋势`，只要一条线 | `c-trend`（折线**形状固定**用样板间那条 —— 脚本不给数据点，不许自己编点） |
| 数字要配一段解释 | `c-huge` + 下方刻度条上的说明 |
| 数字要和另一个数字比 | `数字对比` |
| 屏幕字里有"没人管 / 失控 / 风险" | 当 `对照` 做，用 `.bad` 那一行 |

**`章节标记` 是唯一不居中的**（左上）。它的作用是在长片里报位置，居中会挡住主体。

**同屏只有一个 L2。** 两个发光块并排出现时，观众不知道先看哪个——`数字对比` 和 `对照` 里"灭"的那一侧就是为了让位。

## 六、硬约束

| 项 | 值 | 谁管 |
|---|---|---|
| 一块板 | **一个 `kind`**，元素 2~3 个 | 脚本 |
| 同屏 L2 发光块 | **≤1 个** | 生成 HTML |
| 荧光绿 | ≤15% | 生成 HTML |
| 青 / 洋红 | 各 ≤8% / ≤3%，**不同时出现** | 生成 HTML |
| 边框 | 只有 `1px` 与 `1px dashed` 两种 | 生成 HTML |
| 发光 | 模糊半径恒 `10px`，不改 | 生成 HTML |
| 扫描线 | 只加在面板底，**不加在文字上** | 生成 HTML |
| 停留 | ≥3s | 脚本 |
| 元素相邻 | 两个块间距 ≥28px | 生成 HTML |
| 壳 | 一个点一档，共 `frame` / `fold` / `bar` / `bracket` / `bare` 五档 | 脚本给白话名，生成 HTML 换算 |
| 相邻两点 | **不许同壳**，也不许同入场 | 生成 HTML |
| 小标题 | 每个点都有，≤12 字，一块板只一个 | 脚本 |

**亮着的时候也在动**：每个点里必须有一个元素带持续态（见第八节）。**全片不许出现一帧完全静止的画面。**

## 七、零件（小元素）

用来补足一块板，**不单独成点**。

| 件 | 规格 |
|---|---|
| 光点 | 8px 圆，`#39FF6A`，外发光 12px。亮 = 在场 / 灭 = 空心 8px 圈 |
| 状态灯 | 10px 方，圆角 2px。亮 / 灭 / 洋红（坏） |
| 刻度 | 3px 竖条，间隔 26px，高 14px，次色；已点亮的那几根换荧光绿 |
| 端点 | 折线/柱条末端 8px 圆，带 `PULSE` |
| 角标 | L 形，18px 边 / 2px 粗，荧光绿，贴在面板左上与右下 |
| 提示符 | `▸` 或 `›`，荧光绿，字重 700，永远在行首 |
| 单位角标 | 主数字的 28% 字号，次色，底对齐 |
| 网格 | 折线图底：横 4 条 `1px` `rgba(127,168,148,.22)` 虚线 |
| 小标题 `.kick` | 短横（`.tick`，44×2px）+ 等宽标签（23px / 字距 `.24em`）+ 下面一根渐变线。**三个都从 0 长出来**，标签比线晚 160ms | 每张卡的顶部 |
| 分隔线 `.rule` | 一根从中缝往两边长出来的横线，`nt-growx` 0.7s | 关键词和释义之间 |
| 电流束 `.beam` | 一道竖直电流束从左横穿到右，循环。**只能放在 `overflow:hidden` 的壳上**（`frame` / `fold` / `bar`）—— 放在 `bare` / `bracket` 上会漏到面板外，变成一条飘着的绿条 |
| 电磁波 `.ripple` | 一个圆环从中心扩散到 3 倍后消失，循环。任何壳都能放，是"无壳"的点做电磁波的主要手段 |

## 八、动效

**这套的"动"由电的接通与断开承担**：灭 → 亮是入场，亮 → 灭是退场，**亮着的时候也在动**。

所有相位只由两个量算出：`--hold`（距入场过了多少秒，引擎按当前 `t` 写进去）和 `--i`（第几个子元素）。
**相位由 `t` 唯一决定** —— 同一个 `t` 永远渲染出同一帧，渲染器才能逐帧拍。

### 入场

| 名 | 时长 | 手感 | 默认给谁 |
|---|---|---|---|
| `GLITCH-IN` | 420ms | 闪两下再稳住，横向抖 | 巨数字、大数字 |
| `TRACE-IN` | 900ms | 面板先亮，内容从左被"画"出来 | 折线、圆环、流程 |
| `BAR-IN` | 760ms | 柱 / 格从 0 长出来 | 柱、进度 |
| `STEP-IN` | 520ms | 逐行点亮，错峰 140ms | 三步递进、清单 |
| `LOG-IN` | 460ms | 逐行从右滑入，错峰 110ms | 清单 |
| `SWITCH-IN` | 640ms | 上排先亮后灭，下排再亮 | 对照 |
| `TYPE-IN` | 900ms | 逐字打出来（`steps(22,end)`） | 词条释义 |
| `SLAM-IN` | 380ms | 从 1.4 倍砸下来 | 章节标记 |
| `BLINK-IN` | 560ms | 闪两下，比 `GLITCH-IN` 慢一档 | 引语 |
| `FOLD-IN` | 480ms | 沿中缝 `scaleY(.04 → 1)` 展开 | `fold` 壳 |
| `SPLIT-IN` | 480ms | 两排对开：上排往下、下排往上 | `对照` |
| `SURGE-IN` | 620ms | 面板从左揭开，像拉闸 | 有底壳 |
| `WAVE-IN` | 560ms | 主体被电了一下，斜切抖动后归位 | 无壳的点 |
| `GROW-IN` | 640ms | **装饰线先长出来（760ms），内容再顶出来**（延后 120ms 起） | 带 kick 的卡片，最像"信息卡"的一种 |
| `RISE-IN` | 560ms | 整块面板从下往上浮起 | 有底壳、想稳一点的地方 |

**退场统一 `FADE-OUT` 220ms**（`.comp.out`）。在这套语言里"消失"就是断电，不需要花样。

**规则：相邻两点不许同入场；全片至少 3 种。** 上一版只用 11 种、这一版 15 种全用上了——
**种类够多的时候，观感差别比改配色大得多。** 同一个 `kind` 出现多次时按上面的表轮换 ——
`对照` 轮 `SPLIT-IN` / `SWITCH-IN`；`清单` 轮 `LOG-IN` / `STEP-IN` / `WAVE-IN` / `SURGE-IN`；
`关键词 + 释义` 轮 `WAVE-IN` / `TYPE-IN`；`转化` 轮 `FOLD-IN` / `SURGE-IN` / `TRACE-IN`；
`章节标记` 用 `SLAM-IN`；`引语` 用 `BLINK-IN`。

### 持续态

**亮着的时候也在动。全片不许出现一帧完全静止的画面。**

| 名 | 时长 | 手感 | 给谁 |
|---|---|---|---|
| `pulse` | 2.4s | 呼吸，透明度 `1 → .45 → 1` | 光点、端点、状态灯、提示符 |
| `breathe` | 2.6s | 绿光涨落 | `对照` 里"亮"的那一行 |
| `wave` | 3.6s | 每 3.6s 被电一下 | 巨数字、词条 |
| `dash` | 1.6s | 虚线相位向前跑 | 清单行尾 |
| `flow` | 2.2s | 一个光点沿线循环移动 | `转化` 的连线 |
| `flick` | 4s | 每 4s 微闪一次 | 章节序号 |
| `SCAN` | 3.6s | 一条扫光线自上而下走一遍后停 | `frame` / `fold` 的面板，每个点只走一遍 |

写法固定成这一句，相位才卡得住：

```css
.comp.in .pulse{
  animation: nt-pulse 2.4s linear infinite paused;
  animation-delay: calc(var(--hold, 0s) * -1);
}
```

### 默认配方（按 `kind` 给，生成 HTML 时不临场发挥）

| `kind` | 入场 | 持续 |
|---|---|---|
| `大数字` | `GLITCH-IN` + 数字跳涨 | 刻度条 `pulse` |
| `占比` | `TRACE-IN` + 环从 12 点顺时针生长 | 环上端点 `pulse` |
| `数值比大小` | `BAR-IN` + 柱从 0 长，错峰 120ms | 数值最大那行的端点 `pulse` |
| `趋势` | `TRACE-IN` + 折线从左描出 | 末端端点 `pulse` |
| `进度` | `BAR-IN` + 格子逐格点亮 | 当前格 `pulse` |
| `数字对比` | `GLITCH-IN`，两侧同拍 | 亮的那侧 `pulse` |
| `转化` | `STEP-IN` 两块 + `TRACE-IN` 连线 | 连线上 `flow` |
| `对照` | `SWITCH-IN` | 灭的那行 `dash`、亮的那行 `breathe` |
| `三步递进` | `STEP-IN` 逐级，错峰 140ms | 末级节点 `pulse` |
| `关键词 + 释义` | `TYPE-IN` + 词 `GLITCH-IN` | 提示符 `pulse` |
| `章节标记` | `SLAM-IN` | 序号 `flick` |
| `引语` | `BLINK-IN`，慢一档 | 括标 `pulse` |
| `清单` | `LOG-IN` 逐行，错峰 110ms | 行尾虚线 `dash`、行首光点 `pulse` |

**一条产物内至少出现 3 种不同的入场手感。** 全片一个手感等于没设计。
**`SCAN` 每个点最多一次，且只在有底的面板上。** 全屏到处扫是廉价科幻。
