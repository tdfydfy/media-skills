# 素材规格：3:4 单板 · 稀疏呼应

透明素材不是"一条缩小版的视频"，而是**一连串独立的强调贴片**。
本技能只做这一件事，所以规格是硬的 —— `check-template.mjs` 会逐条校验。

---

## 一、一块板的几何与规模

素材默认画布 **1080×1440（3:4）**。它不是手机竖屏，是一块板：
板上没有平台 UI 安全区，四周留白对称（`--pad-x / --pad-y` 各 96px）。

```
┌────────────────────────┐ 1080
│                        │
│   ┌────────────────┐   │
│   │   元素 A        │   │
│   ├────────────────┤   │  ← 关系层（箭头 / 分隔线 / 序号）
│   │   元素 B        │   │
│   └────────────────┘   │
│                        │
└────────────────────────┘
        1440
```

| 约束 | 值 | 为什么 |
|---|---|---|
| 一组元素 | **≤3 个**（2~3 正好） | 一个素材点 = 一组元素 + 它们的关系，超过就该拆成两点 |
| 1 个元素 | 太小 | 大概率缺关系层，补一个对照 / 起点值 |
| 同样元素排布 | **竖排** | 横着铺满在 3:4 里一定溢出 |

**首选关系型组件** `c-flow` / `c-stack` / `c-cmp`（C13~C15）：
它本身就是"一组元素 + 关系"，一个 `c-flow` 就是一个完整的素材点。
单元素组件（C01~C12）可以单用，配上关系层更好。
`c-vs` 是横排的，在 3:4 里会被挤成窄条 —— 竖版对照用 `c-cmp`；
同理 `c-step` 在竖版里换 `c-stack`。

**组件换着用**：相邻素材点换一种，整条素材 2~3 种。三个点全是 `c-cmp` 会很单调。

**`data-safe` 留空**：素材是一块板，由用户自己摆，"中央"没有参照物。

## 二、时间轴：停留 · 空档 · 对齐

三条规则由 `check-template.mjs` 第 9 项强制校验：

**1. 停留 ≥0.8s**（3 个元素的一块板建议 **3~5s**）。短于 0.8s 观众来不及读。

**2. 素材点之间不得重叠。** 一块板上同一时刻只能有一组元素 ——
区间重叠等于两组元素叠在同一块板上，读不出任何一边。

```
✅  0────3.2        7.6────11.0       14.4────18.0
        素材点1            素材点2            素材点3
     └─ 4.4s ─┘   └ 空档 4.4s ┘

❌  0────3.2  ──────┐
                  ├─ 重叠
               5.0──────9.0
```

**3. 相邻素材点留 ≥1.5s 纯透明空档。** 空档就是**让实拍主体露出来**的那段时间。
注意是**纯透明**，不是"退场动画刚开始" —— 退场动画还有 0.4s，
所以实际排的时候：`下一个 data-in − 上一个 data-out ≥ 1.5`，再宽一点更安全。

### 与脚本对齐

时间码来自 `ivh-script-overlay` 产出的脚本 JSON：

- **素材点入点 = 对应句子的结束秒 + 0.2~0.4s**（数字型先听后看）
- 概念型 / 章节型可与口播同步
- **退点 = 入点 + 3~5s**（自己撑住，不跟着句子结束）

锚点机制见 `../../ivh-script-core/text-layers.md`，本支线（素材层）的默认值见
`../../ivh-script-overlay/references/points.md`。

### 总时长

`data-duration = max(data-out)`，模板自动写入合成根，不要手填。
有外拍视频时总时长应与视频一致，末尾留 0.5~1s 余量。

**密度**：60s 口播做 **8~12 个素材点**（其余体裁见 SKILL 的密度档），
平均每 5~7 秒才有一个，中间大段全透明 —— 成片里 70%~85% 的像素是透明的，
`check-alpha.mjs` 会给出这个比例。

## 三、图像素材：三手法，不改原图

要在实拍图上做强调时，三种手法从轻到重：

| 手法 | 效果 | 实现 |
|---|---|---|
| **聚光** | 四周压暗，中心亮 | 半透明黑色遮罩 + `border-radius` 挖洞（`mask` 或 `box-shadow: 0 0 0 9999px`） |
| **圈选** | 目标上画一圈 | SVG 手绘感 `ellipse`，`stroke-dasharray` 擦出 |
| **标注** | 引出线 + 文字 | 折线 + `.c-capsule` 标签 |

三者的共同点是**原图完全不动**，强调层是叠加的 —— 这样原图可以换、可以放大缩小，
标注层不用改。

"图 + 标注"算 **1 个元素**（它们是一体的），再配 1 个关系层元素，正好到 2。

## 四、动效：贴片可以更冲

素材生命周期短（3~5 秒），入场要快、要抓眼：

- `SCALE-POP` / `POP-IN` —— 弹入带过冲，抓注意力
- `MASK-UP` / `MASK-LEFT` —— 擦出，通用
- `BLUR-IN` —— 从模糊聚焦，适合概念浮现
- `HARD-IN` —— 硬切下压，适合警告 / 反差

**同一段素材里 ≥3 种入场动效**（第 9 项**硬线**，不足直接 FAIL）。
