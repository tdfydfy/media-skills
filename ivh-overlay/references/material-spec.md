# 素材规格：3:4 单板 · 稀疏呼应

透明素材不是"一条缩小版的视频"，而是**一连串独立的强调贴片**。
本技能只做这一件事，所以规格是硬的 —— `check-template.mjs` 会逐条校验。

---

## 一、一块板 = 一组元素 + 它们的关系

素材默认画布 **1080×1440（3:4）**。它不是手机竖屏，是一块板：
板上没有平台 UI 安全区，四周留白对称（`--pad-x / --pad-y` 各 96px）。

```
┌────────────────────────┐ 1080
│                        │
│   ┌────────────────┐   │
│   │   元素 A        │   │
│   ├────────────────┤   │  ← 关系层（箭头 / 分隔线 / 序号）
│   │   元素 B        │   │
│   └────────────────┘   │
│                        │
└────────────────────────┘
        1440
```

**为什么必须有关系层**：一块板上只放一个孤零零的数字，观众记不住。
数字要有对照（去年 vs 今年）、要有流向（一线 → 三四线）、要有构成（三层占比）。
"关系"就是这个素材的**意义**。

**规模上限**：一个素材点 **≤3 个元素 / ≤2 组关系**。
超过就拆成两个素材点 —— 一块板上放不下，硬塞就是"第二块屏"，失去贴片的意义。

| 元素数 | 判断 |
|---|---|
| 1 | 太小。大概率缺关系层，补一个对照 / 起点值 |
| 2~3 | 正好（一组元素 + 一条关系） |
| ≥4 | 超限，拆 |

---

## 二、稀疏：只挑值得强调的地方

素材跟着口播的时间轴走，但**不对每一句话做反应**。
它只呼应四类"值得停下来看"的位置：

| 类型 | 口播信号 | 素材形态 |
|---|---|---|
| **章节切换** | "第二部分""接下来" | 提示标签 + 序号（`c-step` / `c-capsule`） |
| **关键概念** | 首次出现的名词、定义 | 词 + 释义（`c-kw` / `c-quote`） |
| **数字 / 表格数据** | 口径、增速、占比、排名 | 数据卡 / 柱 / 线 / 环 / 对照 / 流向 |
| **图像** | 截图、照片、示意图 | 图 + 标注层（见第四节） |

**密度参考**：60s 口播做 **8~12 个素材点**。
换算下来平均每 5~7 秒才有一个，中间大段是全透明的。

> 这是设计，不是 bug。素材成片里 70%~85% 的像素是透明的，
> `check-alpha.mjs` 会给出这个比例。

---

## 三、两条硬规则

### 规则一：素材点之间不得时间重叠

一块板上**同一时刻只能有一组元素**。两个素材点的区间重叠 =
两组元素叠在同一块板上，读不出任何一边。

```
✅  0────3.2        7.6────11.0       14.4────18.0
        素材点1            素材点2            素材点3
     └─ 4.4s ─┘   └ 空档 4.4s ┘

❌  0────3.2  ──────┐
                  ├─ 重叠
               5.0──────9.0
```

### 规则二：相邻素材点留 ≥1.5s 纯透明空档

连续铺满会让叠加层变成"第二块屏"，压住实拍画面。
空档就是**让主体露出来**的那段时间。

注意是**纯透明空档**，不是"退场动画刚开始" —— 退场动画还有 0.4s。
所以实际排的时候：`下一个 data-in − 上一个 data-out ≥ 1.5`，再宽一点更安全。

> 两条规则由 `check-template.mjs` 第 9 项强制校验。

## 四、图像素材：三手法，不改原图

要在实拍图上做强调时，**不要重画原图、不要贴遮罩**。
三种手法，从轻到重：

| 手法 | 效果 | 实现 |
|---|---|---|
| **聚光** | 四周压暗，中心亮 | 半透明黑色遮罩 + `border-radius` 挖洞（`mask` 或 `box-shadow: 0 0 0 9999px`） |
| **圈选** | 目标上画一圈 | SVG 手绘感 `ellipse`，`stroke-dasharray` 擦出 |
| **标注** | 引出线 + 文字 | 折线 + `.c-capsule` 标签 |

三者的共同点：**原图完全不动**，强调层是叠加的。
这样原图可以换、可以放大缩小，标注层不用改。

如果素材点是"图 + 标注"，那么**图和标注算 1 个元素**（它们是一体的），
再配 1 个关系层元素，正好到 2。

---

## 五、动画：动效可以更冲

素材是贴片，生命周期短（3~5 秒），所以**入场要快、要抓眼**。
和独立成片的克制不同，素材允许：

- `SCALE-POP` / `POP-IN` —— 弹入带过冲，抓注意力
- `MASK-UP` / `MASK-LEFT` —— 擦出，通用
- `BLUR-IN` —— 从模糊聚焦，适合概念浮现
- `HARD-IN` —— 硬切下压，适合警告 / 反差

**同一段素材里 ≥3 种入场动效**（第 9 项会给 note）。

**不必用 `data-safe`。** 板由用户自己摆到画面某处，"避开中央"没有参照物。
写了第 9 项会提示"不生效"。

---

## 六、一句话总结

> 一块 3:4 的板，一组有关系的元素，一段 3~5 秒的强调，块与块之间留出透明的呼吸。
