# HTML 制作指引

输入是已确定的策划稿与风格。输出是可以预览、可以按时间定位并交给 ivh-render 的单文件 HTML。

## 阅读与设计

先读策划稿和选定风格的 spec.md。需要理解某种表达关系时，回看 [creation.md](creation.md) 的表达参考。HTML 范例仅在参考具体效果或复用实现时读取，不要求通读所有组件代码。

优先采用风格中的成熟组件。内容基本适合时，调整尺寸、排列、行数、断行和呈现节奏；确实不适合时，沿用同一视觉语言设计新结构。允许复用相同组件和动效，不为追求变化强制轮换。

制作时保留策划稿的事实、核心文案、关系和时间。长文案先尝试重排与分步呈现，需要修改含义或延长时间再说明。临时新结构直接服务当前作品，反复有用时才考虑收录到风格参考。

## 风格与运行基础

风格由 MD 中的视觉原则、参数与组件参考约束。优先复用可用且经过验证的播放、定格和预览实现；视觉布局不必照搬整份模板。

将给人看的组件展厅与交付产物分开。正式 HTML 只包含本片内容及必要的预览功能，避免未使用的示例组件混入渲染时间轴。风格目录下的 `showcase.html` 就是给人看的展厅：看形态、看动效、抄实现时读它，不要整块搬进产物。

## 最小出片接口

以下约定用于对接现有 ivh-render。组件的内部结构、类名和入场方式由设计决定。

| 项目 | 约定 |
|---|---|
| 文件 | CSS、JavaScript、SVG 和必要资源内联；本地打开可工作，不依赖网络字体或 CDN |
| 默认画布 | 1080×1440，透明画布；承载板或面板只随相应内容出现 |
| 正式内容 | 放在 `#track` 内，每个定时内容组使用 `<div class="comp ...">` |
| 时间 | 在上述 div 写 `data-in="18.6" data-out="23.2"`，单位为原片绝对秒，有限数值且结束晚于开始 |
| 区间含义 | `data-in` 开始入场，`data-out` 时完全不可见；入场、停留、退场都在区间内完成 |
| 定格 | 暴露 `window.IVH.seekAt(t)`；直接跳到任意时刻可得正确状态，不依赖先前播放顺序或墙钟 |
| 预览 | `?view=1` 用于有底预览；`?t=秒` 用于定格；默认出片状态无背景、无 HUD、缩放为 1 |

底座另带一层可选效果层：入场关键帧、数字跳涨、生长量和持续态都由属性开启，属性名与相位写法见 `assets/base.html` 顶部注释。不写这些属性的内容与旧版逐字节一致，改底座不影响已有产物。这层与风格无关，具体有哪些动效名由所选风格的 spec 给出，例如 neon-terminal 的「动效」节。

保留源码中的字面量 CONFIG，供当前渲染器读取。字符串使用单引号；HTML 属性使用双引号。STYLE 填实际风格目录名：

```javascript
const CONFIG = {
  PURPOSE: 'overlay',
  BASE: 'timeline',
  BG: 'transparent',
  RATIO: '3:4',
  STYLE: 'soft-relief',
  ANIMATE: true,
  HIDE_HUD: true
};
```

当前渲染器按正式组件最大的 `data-out` 决定素材结束时间，新产物将退场放在 end 之前，保持预览与出片一致。原片时长可以更长，素材无需为凑满原片增加内容。旧模板的退场语义可能不同，复用时核对。

数字和图形都应由当前时刻计算。装饰动画也要可以定格；持续动画按表达需要使用，不要求每个点永远运动。图表比例、方向、单位和显示数值保持一致。

## 交付检查

核对策划稿中的文字、数字和时间是否落实；确认实际产物有内容、没有示例残留，文字没有溢出，默认打开不会把预览背景或控件带入素材。

对入场、停留、退场与空档选少量代表时刻，在浏览器中确认定格和播放工作正常。视觉效果交给用户查看，不用分类数量或样板间锚点替代观感判断。

从仓库根目录运行只读前置检查：

```bash
node ivh-render/scripts/render.mjs path/to/script.html --preflight
```

前置检查通过说明源码满足渲染器的部分条件，不等于已经验证内容或透明视频。交付 `script.html` 的实际路径，说明预览方式与尚未验证的事项。

用户确认效果且已要求出片时，按 [ivh-render](../ivh-render/SKILL.md) 执行。现有渲染器默认将透明素材输出为 ProRes 4444 MOV；其他格式按实际支持情况处理。
