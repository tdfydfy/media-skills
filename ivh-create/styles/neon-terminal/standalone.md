# Neon Terminal · 独立视频

先读 [spec.md](spec.md) 的共同视觉语言，再结合本文件选择全屏场景。制作遵循 [独立 build](../../modes/standalone/build.md)，运行底座使用其中的 `--local` 时间契约。

## 一种身份，两种光照

暗场像正在工作的终端，浅场像打开终端后的工作台。字体、直角结构、状态标记、主强调色和对象身份贯穿全片；明暗、密度、景别和动作随叙事改变。不是把暗场 CSS 做颜色反转。

| 设计项 | 暗场 / signal | 浅场 / workspace |
|---|---|---|
| 画布 | `#06100C`，局部 `#0C1D14` | `#EDF4EE`，局部 `#FAFCF9` |
| 主文字 | `#EAFFF2` | `#10271B` |
| 次文字 | `#A3BEAD` | `#466454` |
| 焦点 | `#39FF6A` 小面积绿光、亮条、端点 | `#39FF6A` 实色选区配深字；强调文字用 `#087638` |
| 线 | `#284D38`，激活后变绿 | `#B8CBBD`，焦点线用深绿 |
| 材质 | 局部网格、单次扫描、克制光晕 | 清晰分区、细线与偏冷纸底，正文无外发光 |
| 用途候选 | 概念、问题、状态接通、集中结论 | 操作、拆解、对照、证据阅读 |

A/B 可以同明暗，也可跨明暗；上述用途是候选，不固定分配。浅场不能用荧光绿写小字，暗场不能把次文字压得难以阅读。一个焦点允许由文字、对象和连接线共同组成，不要求只有一个亮像素。

反差优先发生在语义转折：提出问题后进入操作、从细节退出给结论。反差可以来自全屏视频或构图变化，不强制每隔一幕切换黑白。绿色全屏冲击仅在确有表达目的时短用，不作为常驻底色。

## 画幅与文字

正式比例、宽高像素和风格须按 [workflow](../../modes/standalone/workflow.md#开工设置由用户选择) 由用户选择。展厅 1920×1080 只用于演示，不能代替正式作品设置。

- 以 1920×1080 为参考：左右安全边距约 96～120px，顶部约 72px，底部保留约 140～170px 字幕区域。背景可以满幅，关键文字和操作结果不要占字幕区。发布平台额外遮挡按实际项目调整。
- 主标题约 88～120px，正文约 32～40px，对象标签约 26～32px；展厅中的小号英文眉题是辅助标识，不能承载唯一的关键信息。
- 一屏通常突出一个解释任务。标题和主体可以同屏、先后出现或交接焦点；不强制标题固定在上半屏。
- 竖屏重排对象关系：左右布局改为上下推进、操作界面裁到关键区域、标签重新定位。不能把整个横版等比缩进竖屏并认为完成适配。
- 中文无衬线，数字与短英文使用等宽。标题不强制等长；在固定时间内无法阅读时先分步展开，而非无限缩字。

## 场景候选

| 任务 | 画面组织 | 动作与切换 | 展厅参考 |
|---|---|---|---|
| 概念 / 隐喻 | 大标题与具象化关系图；必要时生成背景、主体、前景图片 | 杂项出现、焦点建立、无关项减弱、关系接通 | N01：信息筛选 |
| 操作 / 演示 | 真实录屏或明确标注的示意界面，主操作区域优先 | 选择、动作、结果分拍展开；标注跟随对象 | N02：批量归组 |
| 转折 / 结论 | 让上场的对象变成核心词或结果，减少同时可见的信息 | 明暗切换后落稳；强调线承担句子间连接 | N03：下一步行动 |
| 全屏 B-roll | 图片或视频满幅，按需加局部暗衬、短标签或裁切窗口 | 叙事切入、局部推近、细节揭示；保留素材本身信息 | 按实际素材制作 |
| 数据 / 证据 | 有来源的数据图形、截图、引用；标签与口径保留 | 先对象后数值，焦点转移而非整图闪烁 | 适配 overlay 组件 |
| 回顾 / 收尾 | 前面出现过的对象或步骤回到同一平面 | 对象延续、顺序归位、结论稳定停留 | 可从 N03 变体制作 |

这是一组可组合的场景参考，不是穷举的类型表。数字与图表必须有依据，操作示意不能假冒产品录屏。展厅的文字、操作结果与时长仅为演示，不直接带入用户作品。

## 图片、视频与分层动画

图片尽量通过构图、裁切与局部标注融入终端语言，不要求给每张图套发光框。真实截图保留可辨识颜色；只在不影响事实时调整材质或色调。全屏 B-roll 上有字时，对字的区域加局部对比保护。

生图 API 当前未接入。需要概念图片时先说明视觉隐喻、层次、主体一致性和运动余量，结果落入本地素材目录后再参与动画。可先用 SVG/HTML 或用户提供的图片跑通场景，不为风格展厅伪造生图产物。

分层示例：背景缓慢推近，主体从边缘进入，前景标签先后出现，最后收束到一个对象。各层按当前局部时间计算，镜头与内容动作避免同时争夺注意。整图只有轻微推近也可能足够，复杂分层不作为配额。

视频仍用独立底座的全局时间／源入点映射，出片等待定位完成。需要在剪辑软件补入时，明确整屏替换还是下层素材；上方标注需要保留则单独导出透明前景。

## 独立时间轴的动作写法

overlay 的 `--hold`、`--exit`、`data-type`、`data-to` 等并不是独立底座的 API。复用组件时迁移实际 CSS/JS，不能只复制属性名。独立底座给每个时间组写 `--local`（秒）和 `--progress`：

```css
.reveal {
  animation: reveal .7s cubic-bezier(.2,.75,.2,1) both paused;
  animation-delay: calc(var(--delay, 0s) - var(--local, 0s));
}
@keyframes reveal {
  from { opacity: 0; transform: translateY(24px); }
  to { opacity: 1; transform: translateY(0); }
}
```

需要同一元素先进入再移动时使用嵌套层，每层负责一种变换，避免两条 animation 争抢 transform。场景背景默认直接切换；为过渡有意重叠时明确层级与持续时间，不沿用 overlay 全组淡出造成底片黑闪。

持续态优先沿信息关系运动，例如线条接通、选择范围扩展；装饰可以停止。展厅中的所有动作由暂停的关键帧和局部时间驱动，任意时刻可直接定位。

## 展厅与复用

打开 [standalone-preview.html](standalone-preview.html)，点击播放或选择场景。动画源文件是 [standalone-showcase.html](standalone-showcase.html)，可用 `?t=秒` 定位；源码按 N01、N02、N03 ID 查找内容，样式按 `concept`、`workspace`、`conclusion` 查找。

展厅使用独立底座播放逻辑，展示 24 秒、三个连续场景，无音频、无外部媒体、无生图依赖。它是设计与实现参考，不是最终作品模板清单。正式作品只复用所需结构，仍从已确认脚本出发；更新运行逻辑时优先维护独立底座，再同步展厅。
