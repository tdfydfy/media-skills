# Neon Terminal · 霓虹终端

## 表达倾向

发光界面落在实拍画面上，通过明灭、亮条和接通顺序强调信息。适合数字、状态变化、对立关系与行动提示。内容策划时可参考下方组件形态，HTML 阶段再确定布局。

## 保持风格的依据

- 正文以近白为主，荧光绿集中在线、状态和焦点上。大段绿字会降低可读性。
- 层级主要依靠亮度、发光强度与暗面板；维持清楚的视觉焦点。
- 数字和英文使用等宽字体，中文使用系统无衬线。
- 根据宿主画面选择暗底、亮条、括标或无壳。未见实拍时，优先用局部暗底保障可读性。

以下参数是统一起点，可为具体内容成组调整，保持层级关系：

| 项目 | 参考值 |
|---|---|
| 主强调 | `#39FF6A` |
| 正文 / 次文字 | `#EAFFF2` / `#7FA894` |
| 局部暗底 | `rgba(4,12,8,.82)`，需要时调整不透明度 |
| 次维度 / 警示 | `#2BE7FF` / `#FF3D8B`，按语义少量使用 |
| 字体 | 中文 PingFang SC / Microsoft YaHei；数字 ui-monospace / Consolas |
| 字号起点 | 核心数字 132～190px，标题 72px，词条 84px，正文 36px，标签 26px |
| 线与装饰 | 面板边线约 1px，重点亮条约 4px，角括标约 18px |

```css
/* 有底面板参考 */
background: rgba(4,12,8,.82);
box-shadow: 0 0 0 1px #39FF6A,
            0 0 18px rgba(57,255,106,.5),
            inset 0 0 22px rgba(57,255,106,.10);

/* 无底文字的局部暗衬参考，仍需结合实际背景检查 */
text-shadow: 0 0 4px rgba(2,8,5,.95),
             0 3px 16px rgba(2,8,5,.92);
```

## 常用组件参考

| 组件形态 | 组织方式 | 可调整的位置 |
|---|---|---|
| 终端数字 | 等宽大数字配简短标签，下方可接刻度条 | 是否有底、单位位置、重点亮度 |
| 明灭对照 | 两组信息分上下或左右，以亮度突出当前重点 | 顺序、标签和焦点；较暗不自动代表错误 |
| 接通流程 | 节点之间用亮线连接，沿信息方向依次点亮 | 节点数量、方向与时间顺序 |
| 数据轨道 | 暗轨道与发光填充搭配，读数靠近端点 | 条形、环形或刻度条，长度跟实际比例走 |
| 终端列表 | 简单行首符号、短文本，必要时用弱线连接 | 行数、分组、逐项出现 |
| 词条与结论 | 大词或短句配亮条、括标，解释降低一级 | 断行、位置、是否需要眉题 |

带底、折叠、亮条、括标、无壳都是可用的外观参考，按可读性和内容选择即可。不要求全片用齐，也不强制相邻两点换壳。

## 动作

可用接通、描线、逐项点亮、折叠展开或轻微闪动帮助表达。常见入场约 400～800ms，退场约 220ms；阅读稳定性优先于动效数量。

持续感可以来自小光点、局部呼吸或沿线移动，避免整屏同时闪烁。扫描、电流等装饰控制在所属面板内，不覆盖正文。所有动态遵守生成指引中的时间定位接口。
