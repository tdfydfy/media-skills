# Soft Relief · 柔面凸凹

## 表达倾向

浅色物件的触感，安静、清晰，层级来自凸起与凹陷。适合解释、数据、前后关系与少量并列信息。内容策划时可参考下方组件形态，HTML 阶段再确定布局。

## 保持风格的依据

- 内容放在不透明浅色承载板上，板外透明。承载板随内容一起离场。
- 光源保持左上方向；凸起用外部双影，凹陷用内部双影。承载板与实拍之间使用单侧暗投影，避免透明边缘出现大片白晕。
- 文字通过大小、深浅和位置形成主次，默认深色文字；强调色只用于当前焦点。
- 用凹槽、间距和体积区分区域，避免把主要结构画成硬边框或霓虹描边。

以下参数是统一起点，可为具体内容成组调整，保持层级关系：

| 项目 | 参考值 |
|---|---|
| 板底 | `#E4E9F0` |
| 主文字 / 次文字 | `#3D4A5C` / `#6B7A90` |
| 亮影 / 暗影 | `#FFFFFF` / `#A3B1C6` |
| 强调 / 对照 | `#E8555A` / `#4A90D9`，按需要少量使用 |
| 字体 | 系统无衬线，中文优先 PingFang SC / Microsoft YaHei |
| 字号起点 | 核心词 96px，数字 120px，标题 40px，正文 30px，标签 24px |
| 板宽与圆角 | 1080px 画布上宽约 760px，外圆角 40px，内部圆角 16～28px |

```css
/* 凸起参考 */
box-shadow: -6px -6px 12px rgba(255,255,255,.92),
             6px  6px 14px rgba(163,177,198,.55);

/* 凹陷参考 */
box-shadow: inset -5px -5px 10px rgba(255,255,255,.92),
            inset  5px  5px 12px rgba(163,177,198,.50);
```

## 常用组件参考

| 组件形态 | 组织方式 | 可调整的位置 |
|---|---|---|
| 数字与归因 | 大数字直接落在板上，下方短说明放进凹槽 | 单位位置、数字大小、说明换行 |
| 上下对照 | 两组信息竖排，中间用间距或细凹槽分隔 | 两组等重或突出重点，标签位置与宽度 |
| 转化关系 | 两个节点之间放方向连接，关系词靠近连接 | 节点数量、连接方向、逐步揭示 |
| 比例与进度 | 凹陷轨道承载凸起填充，数值在近处标注 | 横向轨道或环形，标签位置 |
| 清单与导航 | 条目逐行排列，需要强调的当前项轻微抬起 | 行数、分组、错峰出现；过长时拆分 |
| 关键词与引语 | 字本身成为焦点，辅以一条凹槽或简短解释 | 居中或左对齐、字重与断行 |

这些形态可直接采用，也可按内容重组。板内留白和清晰层级比塞入更多凸凹装饰更重要。无需每张卡同时包含标题、数字、说明和装饰。

## 动作

入场适合轻微顶起、压入或逐项落下，约 300～450ms；退场适合轻轻压回，约 240ms。用动作帮助读者跟随信息，避免大幅弹跳。

需要持续感时，可缓慢改变板的投影或局部焦点；内容稳定后也可以安静停留。所有动态遵守生成指引中的时间定位接口。
