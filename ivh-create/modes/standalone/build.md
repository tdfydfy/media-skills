# 独立视频 HTML 制作

输入已确认的策划稿与风格，输出可加载本地素材、随时间定位的 HTML 和无声视频画面。流程与作品目录见 [workflow](workflow.md)。

## 视觉落实

先通览整片场景与风格参考，再统筹主画面、B-roll、标题、字幕、背景和转场。字体、强调色与对象身份保持连贯，明暗、色彩面积、构图密度、景别与运动节奏可以形成反差。A/B 不固定上下分带，也不固定黑白角色；每次变化应呼应解释、冲突、证据或结论。

共享 [soft-relief](../../styles/soft-relief/spec.md) 与 [neon-terminal](../../styles/neon-terminal/spec.md) 是视觉候选。风格有模式分流时，继续读取其 standalone 规范与场景参考；neon-terminal 见 [独立场景规范](../../styles/neon-terminal/standalone.md)。透明面板尺寸与留空规则不适用于全屏场景。可在同一视觉语言中设计浅／深变体，注意文字对比度和素材色调统一。先用代表性的概念、演示、转折场景校准设计，再展开整片；不新增强制审核阶段。

演示优先展示动作和结果，镜头移动、遮罩揭示、局部高亮与信息分步出现围绕口播展开。稳定阅读处允许静止。文字、数字和精确图形使用 HTML/SVG；图像用于环境、主体与隐喻，避免整片成为重复的静态海报。

## 本地素材与生图

CSS、JS 和 SVG 可内联，图片、音频、视频使用作品 `assets/` 下的相对路径，不依赖 CDN、网络字体或临时远程地址。记录来源，交付时带齐依赖；移动作品后仍应可预览。

本项目目前未接入生图 API，基础制作不依赖生图。需要生成图片时先在策划中记录构图、分层、透明背景及动作要求；已有本地图片可直接使用。只有执行环境确实提供可用生图工具且任务需要时，才读取对应 imagegen 技能／工具指引并调用，不把技能文档存在视为 API 已接通。

后续接入生图时，按策划制作整图或分层图，保留构图留白、运动余量与跨场景主体一致性，结果保存到作品 assets/images/ 后沿用本地素材流程。通过叠加、进出、位移、视差、推近、遮罩和焦点切换组织动画。工具不可用时说明素材缺口并采用已允许的替代方案，不把占位图宣称为已生成素材。

背景、主体与前景按需拆层，不强制每张图片都分层。精确文字和数据留在 HTML。图片加载或视频解码失败必须显式报告，不能悄悄导出空白场景。

## 底座与时间契约

从 [assets/base.html](assets/base.html) 复制运行底座，替换其中演示内容与标题。底座的 1920×1080 仅为示例，正式作品使用 workflow 中用户选定的比例、尺寸与风格；同步 CSS 尺寸、`#stage` 的 `data-width` / `data-height` 字面量与 CONFIG，STYLE 填实际选定风格。以下 CONFIG 仅示范格式：

```js
const CONFIG = {
  PURPOSE: 'standalone', BASE: 'timeline', BG: 'opaque',
  RATIO: '16:9', STYLE: 'custom', ANIMATE: true, HIDE_HUD: true
};
```

- 正式时间组使用 `#track` 下的 `<div class="comp" data-in="0" data-out="8">`。区间左闭右开，最后一场在总时长端点保留末态，避免导出尾帧闪黑。
- 场景使用 `data-scene`，必须从零覆盖到音频约定终点；允许有意的转场重叠，不能靠一层永久背景掩盖遗漏的场景。
- 全屏背景默认直接切换，避免所有场景整块淡入淡出造成黑闪；需要过渡时显式安排重叠、层级与子元素动作。
- `--local` 是该组的局部秒数，暂停的 CSS 动画通过负 delay 定位；`--progress` 是区间归一化进度。任意跳转应还原相同状态，不能依赖播放历史或随机数。
- `window.IVH.seekAt(t)` 返回 Promise，完成图片加载、视频定位后才完成。`?t=秒` 用于定位；`?view=1` 显示预览控件，默认导出状态不出现控件。
- `max(data-out)` 必须等于约定总时长。仅填写 `data-duration` 不能覆盖当前渲染器的时长推断。

## 声音与视频

预览音频放在 `<audio id="narration" src="assets/audio/voice.wav" preload="metadata">`。无需声音预览时删除 src 或 audio 元素。预览由用户点击播放，以音频 `currentTime` 驱动画面；无音频时使用预览时钟。拖动定位后暂停，再点播放继续。音频仅用于预览，导出仍是无声视频。

视频使用下面的显式时间映射，禁止 autoplay 依靠墙钟推进：

```html
<video src="assets/videos/demo.mp4" muted playsinline preload="auto"
       data-start="18.2" data-end="31.6" data-source-in="4" data-rate="1"></video>
```

源时间 = `data-source-in + (全局时间 - data-start) × data-rate`。底座只支持正速、非循环片段，区间必须在源视频范围内；循环应显式分段或先准备循环素材。视频同时应位于相应的时间组中。素材原声不参与导出。

本地视频与异步素材使用 CDP 出片（默认 auto 会先尝试 CDP）。带 `data-ivh-async-media` 标记的 HTML 若 CDP 不可用会停止，不能退回无法等待媒体就绪的 CLI 截图。普通同步透明产物保持原有回退。视频格式以当前 Chrome/Edge 实际解码结果为准，先对所用素材验证目标时刻和反向跳转。

若视频定位不可靠，在策划中改为后期补入：明确区间、源入点、速度、裁切；需要保留其上方的标题或标注时另交透明前景。标明透明文件使用全片绝对时间还是局部零点。正式底片可以保留约定背景，不能保留“素材待补”等审核提示。

## 验证与交付

核对策划事实、时间覆盖、文字溢出、字幕安全区、明暗节奏和素材实际加载。媒体定位、跨场景跳转与末帧是新底座的工程验证重点；普通作品不默认逐场截图或先渲染全片。`--preflight` 仅检查部分源码约定，不验证媒体加载或观感。

```bash
node ivh-render/scripts/render.mjs <作品目录>/script.html --preflight
```

交付 HTML 和预览入口，按 workflow 等待效果审核。已获出片授权后：

```bash
node ivh-render/scripts/render.mjs <作品目录>/script.html --out <作品目录>/exports
```

最终交付无声 MP4，与原音频在剪辑软件中从零点对齐；核对成片起止、尺寸与无音轨状态，尾部帧量化误差应控制在交付帧率的一帧内。按需附后期补入素材与透明层，说明尚未验证的内容。
