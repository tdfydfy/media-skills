# 独立视频策划

输入音频、SRT 与素材，输出一份 `script.md`。核心问题是：观众此刻看什么，这个画面如何承接上段并推进叙事？按语义与动作组织连续场景，不把字幕逐句转换成卡片。

## 时间与叙事

先通读全稿，核对音频实际时长、SRT 起止与偏移，识别问题、解释、案例、转折和结论。默认保留原音频顺序、停顿和速度。需要修改音频结构时提出建议，不在画面中暗自压缩时间。

以原音频零点为画面零点。场景覆盖到约定终点，包括开头静音与尾音；SRT 最后一条的结束时间不必然是音频结束时间。字幕有整体偏移时记录映射，必要时先校准。具体数字与结论避免在口播揭示前出现。

每场可以含多个镜头或操作步骤。场景时长由解释量、操作和阅读量决定，不设固定幕长、章节数、A/B 比例或切换频率。全程覆盖可以是稳定停留的画面，不要求每秒运动。长音频自然分章，短片可以直接进入问题，无需强制目录或片头。

## 主叙事与 B-roll

- 主叙事承接口播逻辑：有真人时可用真人 A-roll；只有音频时由概念图、主题视觉或持续演示承担主画面。不为凑 A-roll 强行生成主持人。
- B-roll 用于展示对象、证据、案例或细节，可以全屏切入、画中画或并排出现，不固定在下半屏。
- 标题、标签、字幕与背景单独规划。字幕忠实承接声音，标题提炼，标签说明对象，避免三层重复。字幕是否烧录或留给后期须明确。
- 概念可以用 SVG/HTML、生成图片或混合表达；真实操作优先使用实际截图或录屏。示意界面注明“操作示意”，不能把生成图当作事实证据。

表达关系、信息压缩与数据口径可参考 [透明模式 creation 的表达参考](../overlay/creation.md#表达参考)，不继承其稀疏覆盖和卡片间留空规则。

## 视觉节奏路线

先确定整片的字体、强调色、对象身份与图形语言，再按内容设计反差：浅底讲解／深底冲突、稳定全景／动态特写、留白／密集证据、图解／实拍。A/B 可以相似也可以相反，明暗不与 A/B 固定绑定，不机械轮换背景。

在稿首用几句话写清这条路线及转折理由。每场说明主体、焦点、进入与离开的关系；延续同一个对象、颜色或动作可以在强烈反差中维持连贯。

## 先设计动作，再列素材

概念画面先说明隐喻与展开过程，再判断需要整图或背景、主体、前景分层。生图需求注明构图留白、透明背景需求、人物或物体一致性、镜头运动预留空间。适合精确控制的文字、数字、路径和图表由 HTML/SVG 叠加，不烘焙进生成图。

素材记录来源、预期用途、已有／待制作状态与替代方式。视频写清本片区间和源素材入点；涉及变速、循环、裁切时明确说明。优先 HTML 内合成，解码或逐帧定位不可靠时改为后期补入。全屏替换给出区间；若有前景标注需保留，还应计划透明前景层及其对齐方式。

## 策划稿示例

稿首记录输入路径、画幅、风格、实测总时长、时间映射、字幕策略和视觉节奏。逐场只写有用的信息，不要求重复填写空字段。

```markdown
## S03 · 18.2–31.6 秒｜批量处理

来源：字幕 8–12；音频原时间，无偏移。
画面任务：看懂逐项处理与批量处理的差别。
主体：同一界面，先单项，再框选并执行；真人不出镜。
屏幕文字：一次处理多个任务；底部保留字幕安全区。
关键动作：22.4 秒框选，25.8 秒执行，结果保留至下一场。
视觉：浅底解释切入深底演示，强调色与选中状态延续。
素材：assets/videos/batch.mp4，源片 4.0 秒起，原速。
制作：优先 HTML 合成；不可用时后期替换并另交透明标注。
```

交付前核对：时间全覆盖、事实有来源、画面确实推进理解、素材方案可执行、文字有阅读时间、明暗和动作变化有理由。按 [workflow](workflow.md#阶段交付) 交付策划稿；本阶段不制作 HTML 或调用生图模型。
