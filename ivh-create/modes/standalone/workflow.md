# 独立视频画面工作流

围绕已有音频与 SRT 制作连续的完整画面，交付无声 MP4。用户将视频与原音频分别导入剪辑软件，按零点对齐。音频用于策划、对齐与 HTML 预览，不自动重剪、变速或合入成片。

## 从当前进度继续

| 输入 | 执行 |
|---|---|
| 音频、SRT、文稿与已有素材 | 读 [creation.md](creation.md)，交付 `script.md` |
| 已确认的策划稿 | 读 [build.md](build.md) 与选定风格，制作 HTML 和必要素材 |
| 当前 HTML 的修改意见 | 读取本片策划、HTML 与相关素材，按反馈修改 |
| 已确认 HTML 且要求出片 | 按 [ivh-render](../../../ivh-render/SKILL.md) 导出无声视频 |

只有 SRT 可以先策划，缺音频则标明总时长和同步未验证；只有文稿不把估时当作实测时间。

## 开工设置：由用户选择

正式策划前明确以下三项，已有选择直接沿用，只询问缺失项，可以一次合并询问并提供推荐组合：

| 设置 | 选择内容 |
|---|---|
| 视频比例 | 如 16:9、9:16、4:3、3:4 或自定义 |
| 输出尺寸 | 明确宽×高像素，如 1920×1080、1080×1920；比例不能替代分辨率 |
| 视觉风格 | 现有风格、自定义参考或用户认可的组合；明暗变体仍可按场景设计 |

用户明确委托代选时可推荐并落实，否则不能把底座的示例参数当作已选择。用户给出完整尺寸时可推导比例，无需重复询问；比例与尺寸冲突时先澄清。H.264 默认 yuv420p 输出采用偶数宽高，遇到不兼容尺寸说明并确认调整。将选择记录在 script.md 稿首；后续制作同步应用于布局、CONFIG 和画布尺寸。

## 阶段交付

默认先交付 `script.md` 供内容审核，再交付 `script.html` 与 `preview.html` 供效果审核，各阶段交付后结束当前轮次。脚本确认放行 HTML；HTML 效果确认且已有出片请求才渲染。用户明确要求跳过审核或修改后继续时，按已授权范围执行。整体“生成视频”的请求不自动代表跳过审核；已确认的版本不重复审核。

修改事实、口播对应时间或素材方案时同步策划稿。预览须说明是否含实际音频、是否有待补素材、哪些片段准备在剪辑软件合成。审核占位不能进入正式成片。

## 作品目录

每次制作、修改或重新渲染，在输出根目录下新建按主题命名的文件夹，默认 `outputs/<主题>/`，重名追加 `-01` 等序号。开始时说明绝对路径。同次执行沿用目录；后续续做复制需要的已确认文件与本地依赖，保留历史结果。只读检查或讨论无需新建。

| 路径 | 用途 |
|---|---|
| `script.md` | 唯一策划明细，含素材来源与必要的后期补入说明 |
| `script.html` | 唯一画面与动画源文件，使用相对路径引用本地资源 |
| `preview.html` | 跳转到 `script.html?view=1` 的快捷入口，保留普通链接作为后备 |
| `assets/images/`、`assets/videos/` | 本片使用的图片、视频与分层素材 |
| `assets/audio/` | 按需保存原音频的预览副本，不修改原音频 |
| `exports/script.mp4` | 完整无声画面，渲染显式指定 `--out <作品目录>/exports` |

仅创建实际需要的目录。确需后期合成时，按场景交付原始视频、必要的透明前景层；时间、素材入点、速度与摆放关系统一写在 `script.md`，不另维护重复清单。透明前景由 overlay 契约制作并交 ivh-render；跨模式辅助产物仍属于当前作品。

交付实际文件链接、零点对齐方式与尚未完成的事项。渲染失败或保留帧时报告临时文件位置。不要把仅通过源码检查描述为已完成音画或媒体解码验证。
