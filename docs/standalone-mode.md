# 独立视频模式：持久约定与恢复点

2026-09-18：在 ivh-create 内新增 standalone 模式，与 overlay 共用一个简短 SKILL 路由及 ivh-render。模式入口为 `modes/<模式>/workflow.md`，各自维护 creation、build 和底座。旧版 standalone 技能仅作历史参考，不恢复 JSON 盖章、固定上下 A/B 分带、固定幕长或组件配额。

用户确认的边界：已有音频与新增视频分别放入剪辑软件；独立模式导出完整无声画面，默认保留音频绝对时间。图片和视频置于作品目录供 HTML 相对路径读取；视频优先统一合成，不适合时后期补入，必要时另交透明前景。A/B 可以视觉相近或形成反差，整片有连贯身份而非始终同一明暗。概念支持生图分层与 HTML 动画结合。

当前实现：两套文档、独立底座（连续场景、明暗演示、音频预览、本地图片与非循环正速视频映射）；CDP 等待异步 seek，媒体错误中止，异步产物禁用 CLI 回退。原透明底座迁移时保留运行逻辑。画布显式尺寸由 #stage 的 data-width/data-height 提供，缺失时仍按 RATIO 回退。

验证范围：standalone.test.mjs 已通过，覆盖本地图片、视频源偏移、反向定位、最后一帧、音频预览定位、无声导出、媒体异常与 CLI 拦截；direct-frames.test.mjs 与 cleanup.test.mjs 共 4 项原有回归通过，技能格式与文档链接检查通过。已抽取独立底座明暗交界与末帧。浏览器播放按钮的有声人工试听、真实音频长样片、实际生图分层观感与不同视频编码兼容性仍按具体作品验证，不因底座工程测试通过而宣称完成。
