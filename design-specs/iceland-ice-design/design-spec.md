# 冰川层理 · Glacial Strata
**视觉色彩规范 v1** — 取自 `ccorest-iceland-8498630`

> 冷 + 浅底 + 近乎单色。整套四套里唯一没有暖色、也没有直射光的一套，补的是「冷 + 浅」这一格。

---

## 00. 一句话定位

灰白天、雾吃掉地平线、巨大浮冰横躺，冰体里横贯着几百年前火山灰压成的深色条纹。光无方向、无影子，颜色只有一种——从冰芯里透出来的青。

**调性：冷寂 glacial · 层理 strata · 悬浮 suspended**

情绪落点：温暖↔清冷 = 4% ｜ 安静↔热闹 = 96% ｜ 有机↔几何 = 30% ｜ 抽象↔具象 = 52% ｜ 低沉↔高扬 = 22%

## 02. 用色硬约束

1. **只有一个色相** —— 全页只允许青（170°–195°）。中性灰必须不带色相，混进一丝暖就变成「旧照片」而不是「冰川」。
2. **冰蓝只做面，不做点** —— `#A6D0D7` 与画布对比仅 1.3:1，小色块会直接化掉。需要被看清的标记一律用冰芯或更深。
3. **冰蓝总量 ≤ 25%** —— 它是冰的体积，不是底纹。
4. **深色只在底部或整块** —— 玄水要么整块底，要么贴底横带，不零散撒在画面中间。
5. **不用纯白、不用纯黑** —— 最亮 `#F5F8F7`，最暗 `#182729`。
6. **灰纹不与文字紧邻** —— 暗色细线贴正文会读成删除线，至少留 12px。

**对比度底线**：正文 4.5:1（冰芯在雾白上仅 2.7:1，绝不能做正文；幽蓝 5.0:1 可用）｜大标题 3:1（细字实际按 4:1 执行）｜图表面积色可低至 1.3:1，但必须配标注。

## 03. 字体

- 中文 思源黑体 Regular；英文 Inter / Helvetica Neue。字重只到 **300 / 400 / 500**，这套语言里没有重音。
- **字距是四套里最宽的一档**：标题 +12%、注解 +10%。雾里的空气感全靠字距，比调字号有效。

| 层级 | 字号 | 字重 | 字距 | 行距 |
|---|---|---|---|---|
| 主标题 | 100–140 px | 300 | +12% | 1.15 |
| 章节标题 | 58–72 px | 400 | +10% | 1.22 |
| 二级标题 | 36–44 px | 400 | +7% | 1.36 |
| 正文 | 24–28 px | 400 | +2% | 1.80 |
| 数据数字 | 120–200 px | 400 | +2% | 1.00 |
| 注解 | 17–19 px | 400 | +10% | 1.60 |

行长 ≤15 字，一律左对齐到同一条竖轴，数字用等宽老式。

## 04. 版式：三段式分层

**这是跟其他三套差别最大的一条：画面有明确上下分层。**

| 段 | 占高 | 内容 |
|---|---|---|
| 上 · 雾 | 22% | 纯留白或一行 kicker。放任何内容都会破坏失重感 |
| 中 · 冰 | 50% | 所有信息落在这里，12 列网格，唯一允许出现彩色的区域 |
| 下 · 水 | 28%（≥20%） | 玄水横带贴底，放脚注/页码/来源。没有这层整页会飘 |

层与层交界用**灰纹**（2px、`rgba(78,86,88,.55)`）而不是空白分隔。

- 9:16 改成 **16 / 62 / 22**，底部深色带正好覆盖平台 UI 遮挡区。
- 留白：单屏最多两个信息块，边缘至少 110px。
- 圆角归零（2px），允许 6°–14° 斜切。
- 影：浅底用柔冷影 `0 8px 40px rgba(38,56,59,.10)`，半径大浓度低。
- 边：**霜边**代替描边 —— 内白线 `inset 0 0 0 1px rgba(245,248,247,.70)` + 外冷灰线 `0 0 0 1px rgba(38,56,59,.12)`。

## 05. 六个形态母题

所有图形从这六处生成：

| 母题 | 用途 | 参数 |
|---|---|---|
| **冰脊切面** | 卡片形状、图表分区、内容块边界 | 4–6 边 · 斜角 6°–14° · 圆角 ≤2px |
| **灰纹层** | 分层线、时间轴、进度、沉积序列 | 厚 1.5–4.5px · 间距**不规律** |
| **冰晶点** | 数据点、背景颗粒、密度 | 直径 0.7–1.2px · 不透明度 .5–.7 |
| **融孔** | 空缺、未填、被排除的数据、深度层级 | 椭圆比 1:0.42 · 每层内缩 22% |
| **雾带** | 转场、遮罩、内容与背景融合 | 高 20–60px · 两端淡出 45% |
| **水面镜** | 页脚、脚注区、底部压边、章节收束 | 自上而下 4 层 · 明度每层 -30% |

**材质**：彩色块用 92%–96% 不透明度透出底层（冰的内部透光）；噪点仅 2%–3%（比海面那套少一半）；**不做虚化分层**——这张照片景深极大，远近关系全交给明度。

## 06. 动效

核心是**慢到几乎不动**。海面那套是「水在流」，这里是「冰在等」。

| 用途 | 动作 | 时长 | 缓动 |
|---|---|---|---|
| 背景漂移 | 水平位移 ≤ 画面宽 2%，无限往返 | **40–60 s** | linear |
| 雾起雾落 | 雾带漫过整屏再散开 | 1200–1600 ms | cubic-bezier(.4,0,.2,1) |
| 元素浮出 | blur 8px→0 + 上移 8px + 淡入 | 900–1200 ms | cubic-bezier(.22,1,.36,1) |
| 灰纹沉积 | 自上而下逐条显现，间隔 120ms | 每条 400 ms | ease-out |
| 数据生长 | 面积块自下沿向上撑开 | 1000–1400 ms | cubic-bezier(.33,1,.68,1) |
| 章节转场 | 整屏被雾吞掉 → 换内容 → 散开 | 1400 ms | cubic-bezier(.4,0,.2,1) |

1. 比海面再慢一倍（背景 40–60s vs 20s），但入场要快一点——雾散得比水流快。
2. 位移 ≤ 画面宽 2%，处在「看得出在动、说不清动了多少」的临界点。
3. **转场只能用雾的浓度变化**。横向推移、滑动、缩放都属于海面那套。
4. 入场必须带 blur→0，纯淡入观感完全不同。
5. 只做位移、模糊、透明度，不旋转不缩放不做 3D。

## 07. 图文搭配

- **照片要提亮，不要压暗** —— 这张照片本身很亮很平，叠 30% 雾白蒙版并抬一档亮度。
- 文字落在冰体受光面或雾区，避开灰纹密集处。
- 满版铺图 ≤ 总页数 1/4（有明确具象主体，不是纯纹理）。
- **按层组织内容** —— 不是一二三四条平行列出，而是自上而下叠压：最上面最新、最下面最早，与灰纹语义一致。
- 单屏 ≤25 字。
- 统一调色：曝光 +0.25、对比 -8、高光 +6、阴影 +12、色温 -8、青色饱和 +10（重点是提起暗部、压平对比）。

**适合**：时间与沉积（冰川/地层/长期投资/复利）、严肃克制（研究报告、气候环境、医疗公卫、审计合规）、慢变量（变化极小但不可逆的趋势）。
**不适合**：需要行动号召、需要热情、需要庆祝的内容——这套语言里没有「喊」的语气。
