视觉色彩规范 ／ 六套预设

六套里有五套从一张真实照片或插画里反推而来，第六套是从零设计的材质语言。每套都含配色、字体、版式、 形态母题、动效、层次与边缘手法，以及可直接粘贴的 CSS Token。它们不是六种配色方案，而是六种互不 兼容的视觉语言——空间手段、边缘手法、转场方式、字体重量、节奏快慢全都不重叠，可以并存，但不要混用。

先定位：冷暖 × 深浅

横轴是冷暖，纵轴是画布明度。六个点分得很开，基本一眼就能排除掉四个。

越靠右越暖，越靠上画布越亮。六套里没有两个点挨在一起——这是它们能长期并存的原因。

怎么选

按内容目的匹配，比按审美偏好匹配准得多。

要权威、克制、说服力强

冰川层理

五套里唯一没有暖色、也没有直射光的一套，语言里根本没有「喊」的语气。适合研究报告、气候与医疗、审计合规。

要高级、冷静、数据感强

碎金海面

深底上亮色才跳得出来，所以金色是第一数据序列而非点缀。注意：这与浅底图表「主角用深色」的习惯正好相反。

要温暖、真实、接地气

晨光牧场

高饱和但被柔化，保留照片级肌理与两级景深。适合自然、农业、食品与生活方式类内容。

要讲故事、有一点魔法和危险

暮林星火

逆光 + 粒子是签名，靠三层明度而非透视造空间。唯一一套以插画（而非照片）为原型的语言。

要有活力、推着人往前走

赭石街巷

唯一有镜头语言的一套，节奏最快（背景 10s）。暖色在近处、冷色在远处，颜色本身承担空间分工。

讲演进路径：从 A 到 B

赭石街巷

按纵深组织内容最好用——最近是「现在/这里」，越远越「未来/背景」。roadmap、发展阶段、改造前后都顺。

讲时间与沉积：慢变量、复利

冰川层理

画面本身就是「层 = 时间」。内容按层叠压：最上面最新、最下面最早，与灰纹语义一致。

需要一页里最强的一次强调

赭石街巷 · 招牌红

「一点高饱和压住整片暖色」是这套独有的音量结构——全页只允许一个红色元素，弱元素反而撑起了它。

要让人「看出怎么按」，或手上没有任何图

柔面凸凹

唯一不依赖照片的一套，画面本身就是一件实物。代价是明度空间窄——元素超过 12 个就糊成一片。

一套规范要填满的十六格

每套都按这十六节写，顺序固定。01–11 是静态视觉层，12–16 是视频层——后者不是某一套的补充，是任何一套要进流水线都得回答的问题。判据只有一条：能直接抄成 CSS 才算写完——形容词要配数字，否则等于没写。

格必须给出的内容写完的判据
01 定位与适用一句话定义 + 适用题材 + 避开题材能凭它一眼排除掉一半题材
02 画布与尺度底色 · 安全区 · 主元素占屏 · 间距档 · 留白下限全是具体值，没有「适中」「适量」
03 形状语汇基本形 + 圆角公式 + 形变幅度圆角 / 抖动 / 切角都带 px 或比例
04 层次与边缘边缘手法（投影 / 色调面 / 材质模糊 / 描边，四选一）· L0–L4 分级 · 光源方向 · 语言边界写明「只由 X 承担」，其余手法不参与
05 色彩系统色板 + 每色语义 + 面积占比 + 明度序 + 强调额度每种颜色都有占比上限
06 字体系统6 级字号 + 字重 + 字距 + 行高数值可直接粘进 CSS
07 版式骨架2–3 个骨架 + 重心位置 + 元素数上限说得出「一屏最多放几个块」
08 表面与材质纹理种类 + 强度 + 模糊半径强度是数字（5% / 8px），不是「轻微」
09 运动语汇时长档 + 曲线 + 入场退场 + 背景是否常动曲线写成 cubic-bezier
10 组件映射大数字 / 数据卡 / 引语 / 章节卡 / 对比进度，各写一个五个都能照着直接画出来
11 容错与边界长文本 · 空态 · 超长数字 · 深色降级每条给的是替代方案，不是「不要」
12 画幅与载体横竖两版骨架 + 组件换型表 + 透明载体的承载板（若走透明支线）横竖各给一套值，且不靠模板的 76% 上限兜底
13 幕与节奏一屏几幕 · 构件上限 · 停留时长 · 幕内错开 · 幕间过渡 · 背景是否常动幕内入场与幕间过渡分开定义
14 组件全映射components.md 的 15 个组件各写一个 + 分隔件裁决每个组件都说得出「在这套里是什么形」
15 小元素与动效库状态点 · 徽章 · 箭头 · 开关 · 角标 · 坐标轴 + 专属 keyframes 与注册写法动效名逐字对上模板的注册表，含数值区间
16 在场演化入场之后信息怎么继续动：数字跳涨 · 柱条生长 · 大小对比 · 循环呼吸，各带实现与适用边界每个动作都写明「什么场合别用」——只列能用等于没写

其中 09 / 13 / 15 / 16 四格（运动语汇 · 幕与节奏 · 小元素与动效库 · 在场演化）有一条不随风格变化的公共层—— 定格机制能表达什么、交错与转场怎么写、动效的抽帧成本。它不写进任何一套，单独放在 动效规范 · Motion Spec。 各套只回答「在本套语言里取什么值」。

目录结构：本页是 design-specs/index.html，六套各占一个子目录，每套都是 design-spec.html + design-spec.md + cover.jpg 三件套。各套页面左上角可返回本页。

加第七套：把新目录放进 design-specs/，在本页脚本顶部的 SPECS 数组里加一条（名称、目录名、色板、比例、参数、适合度），定位图与卡片会一起更新。

注意事项：规则不能跨套复用。比如「用虚化做远近」是牧场那套的规定，而冰川那套恰恰要求不做虚化分层；柔面凸凹则一律不用描边与模糊——混用会立刻串味。

前五套色值为视觉采样估算（对原图跑的算法聚类可从简）；第六套是从零设计的材质语言，色值是设计值不是采样值。
