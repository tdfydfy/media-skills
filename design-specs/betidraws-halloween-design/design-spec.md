# 暮林星火 · 视觉色彩规范 v1

> 取自 betidraws-halloween-9916172。用于视频与演示文稿的配色、字体、版式、图形与动效标准。
> 完整可视化版本见 `design-spec.html`。

## 调性

**暮色 dusk · 童话 fable · 星火 spark**

一片暮色里的森林。背景是透过树干的暖雾，中间飘着骑扫帚的红斗篷、仰头嚎叫的狼、蹲在卷曲树枝上的影子；前景堆着三只南瓜，表面结着星芒状的霜。画面漂着成千上万个光点——有圆的、有尖的、有橙的、有白的，像孢子也像火星。

这是**童话式的危险**：暖、好看、有魔法感，但底下藏着暗。不是明快活泼的节日装饰，而是一张有空气、有距离、有体积的夜森插画。

坐标：温暖 7/10 · 安静 4.8/10 · 有机 9/10 · 低沉 7.4/10 · 具象 6.6/10

五条翻译：
1. **逆光，主体压暗** —— 光在背景不在主体上；用深色实心块 + 背景发光衬托，而非亮边深底
2. **三层景深是骨架** —— 前景暗、中景主体、背景发亮；空间感来自三层明度而非透视
3. **粒子永不缺席** —— 星芒与光点铺在每一屏，包括数据页和列表页
4. **保留手绘痕迹** —— 允许 1–2° 倾斜与 ±2% 形变，干净的数字感会毁掉童话调性
5. **暖色承担一切** —— 全套色相落在 0°–45°，没有冷色；拉层次一律改明度

## 用色规则

四种画布：
- **暗画布（默认）**：底 `#1C1008` / `#2B1A12`，字 `#F0E2C8`，对比 12.6:1
- **雾光画布**：`radial-gradient(ellipse, #9A5A28, #5A3319 34%, #2B1A12 68%)` —— 最能代表原画的一层
- **插画画布**：图片上叠 55% 墨夜蒙版，文字用星芒白或蜜金
- **浅画布（备用）**：底 `#E8D5A8`，字 `#3D2418`，强调改 `#C2541F` / `#8E3418`（蜜金在浅底会消失）

六条硬约束：
1. 不引入冷色——需要对比时用明度极端值（星芒白 vs 墨夜）
2. 朱砂红 ≤10%，它是危险信号，铺开就失效
3. 橙色阴影用暗赭红 `#8E3418`，不加黑（`#000` 会把暖橙调脏）
4. 不用纯黑纯白；最暗 `#1C1008`，最亮 `#FFF3D6`
5. 金色只出现在光里（标题、关键数字、星芒），不给整块背景涂金
6. 橙与红相接时明度差 ≥18%，或垫 1px 蜜金细线

对比度：正文 ≥ 4.5:1 · 朱砂红在墨夜上约 4.1:1（可做大标题，不可做正文）· 关键信息不单靠颜色

## 字体

- **标题** 思源宋体 / 方正清刻本悦宋 / 宋体；英文 EB Garamond / Cormorant / Georgia
- **正文** 思源黑体 / 苹方；英文 Inter / Lato（**正文不用衬线**，暗底小字号宋体会糊）
- **可选点缀** 手写体（Caveat / 站酷快乐体），仅限一句金句
- **数字** 等宽或半等宽，字重比正文高一档

1920×1080 基准下：

| 层级 | 字号 | 字重 | 字距 | 行距 |
|---|---|---|---|---|
| 主标题 Display | 100–150px | 400 衬线 | +5% | 1.16 |
| 章节标题 H1 | 60–76px | 400 衬线 | +5% | 1.25 |
| 二级标题 H2 | 38–46px | 600 无衬线 | +2% | 1.35 |
| 正文 Body | 26–30px | 400 无衬线 | +1% | 1.80 |
| 数据数字 Metric | 120–200px | 600 等宽 | 0 | 1.05 |
| 注解 Caption | 18–20px | 400 无衬线 | +6% | 1.60 |

衬线只给标题，一套里不超过三处；一行中文 ≤18 字；文字不叠在粒子上（需压到 30% 以下或用暗底托住）。

## 版式与三景深

空间感不靠透视，靠**三层明度**：

| 层 | 明度 | 放什么 |
|---|---|---|
| 背景层 Backdrop | 最亮 | 雾光底、树影、大块径向光。模糊 8–20px，不承载信息 |
| 中景层 Middle | 中调 | 所有要读的内容：标题、正文、图表、数字。必须清晰无模糊 |
| 前景层 Foreground | 最暗 | 粒子、星芒、装饰草枝。压在内容之上，`pointer-events:none`，透明度 40–70% |

三层缺任何一层都会塌：只有背景+中景会显得平，只有背景+前景读不清，前景太重会盖住内容。

网格：
- 12 列，列间距 = 列宽 1/3，外边距 = 画面宽 8%
- 间距全部是 8 的倍数：8 / 16 / 24 / 40 / 64 / 96
- **16:9**：安全区 84%×84%；径向雾光圆心固定 50% / 62%，跨页不移动
- **9:16**：上 18% 与下 8% 留给平台 UI；光源圆心上移到 50% / 40%；核心信息在纵向 30%–75%
- **前景压边**：每页底部保留 12–16% 的暗色前景带，维持「站在林子里往里看」的位置感
- 圆角：卡片 16px、小元素 8px、标签全圆
- 发光比投影重要：`0 0 32px rgba(217,184,122,.22)`
- 纹理叠在最上：整页 5–7% 颗粒（比常规重），视频里用静态噪点

## 形态母题（所有图形只从这六个来）

| 母题 | 用途 | 参数 |
|---|---|---|
| 星芒 | 关键高光、数据峰值、装饰点 | 四角，长短轴比 1:3.2，直径 8/16/28px 三级混用，尖角不圆化 |
| 光点 | 铺满画面的粒子层 | 直径 1.5–4px，每屏 80–200 个，颜色在白/金/橙/红之间随机，密度上疏下密 |
| 螺旋卷须 | 分隔、装饰角、引导视线、时间轴端头 | 圈数 0.8–1.5，stroke 2–3px，圆头，末端变细 |
| 竖向树干 | 背景纹理、分栏暗示、纵向节奏 | 宽 4–9px，间距 12–24px，不做等距，顶端渐隐 |
| 剪影块 | 主视觉、图标、章节符号 | 单色填充无描边，轮廓留 2–3 个小凸起 |
| 雾光 | 背景光源、焦点衬托、章节页底 | 中心不透明度 ≤50%，椭圆比 1:0.45，边缘渐隐 ≥40% 半径 |

材质与手绘痕迹：
- 颗粒 5–7%，比常规重（颜料与纸面的质感）
- 形状允许 1–2° 倾斜与 ±2% 形变，刻意避开正圆正方
- 三级模糊：背景 8–20px / 中景 0 / 前景粒子 0–2px
- 色块之间用 multiply 或 overlay 的叠加感，交界互渗，不要硬边
- 图标 stroke 2px 且允许不均匀线宽，或直接用剪影块

## 动效

重点是**粒子层的持续漂浮**与光的呼吸，而不是元素入场。整页永远有一层东西在动。

| 用途 | 动作 | 时长 | 缓动 |
|---|---|---|---|
| 粒子漂浮 | 每个光点独立上下漂移 10–24px + 淡入淡出，无限循环 | 6–14s | ease-in-out |
| 星芒闪烁 | 透明度 0.4 → 1 → 0.4，不规则间隔 | 2.5–5s | ease-in-out |
| 雾光呼吸 | 背景径向光缩放 1.00 → 1.04 | 12–18s | ease-in-out |
| 元素入场 | 从暗到亮（透明度 0 → 1）+ 上移 12px | 600–900ms | cubic-bezier(.34,1.2,.64,1) |
| 强调 | 星芒从 0 放大到 1.3 再回落 | 500ms | cubic-bezier(.34,1.4,.64,1) |
| 章节转场 | 粒子密度骤增并加速向上掠过 | 900ms | ease-in-out |

规则：入场像被照亮（不是滑进来）· 粒子各自动画延迟随机 0–8s（同步就是数字感）· 同屏同时闪烁的星芒 ≤3 个 · 光在动景不动 · 缓动允许轻微过冲，但只在入场用

## 插画与图文

原型是插画而非照片，多了两条自由度、也多两条约束：

- **插画要统一语汇**：所有插图元素必须来自六个母题且用同一套色板，混入图库的扁平插画会立刻露馅
- **具象图形可用于图示**：南瓜表示占比、树干表示分组、卷须表示流程
- **图片先压暗**：外部照片叠 55% 墨夜蒙版，色温整体调暖（+12）
- **统一调色**：曝光 -0.25、对比 +14、高光 -10、阴影 -12、色温 +12、橙色饱和 +10、蓝色去饱和 -30
- **文字要底板**：正文区加 `rgba(28,16,8,.6)` 暗底或雾光衬底，把粒子隔开
- **满版可用但压暗**：可用到总页数 1/3，但每页保留底部 12–16% 暗色前景带
