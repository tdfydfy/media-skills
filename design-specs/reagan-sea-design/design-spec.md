# 碎金海面 · 视觉色彩规范 v1

> 取自 reagan_yip-sea-7205366。用于视频与演示文稿的配色、字体、版式、图形与动效标准。
> 完整可视化版本见 `design-spec.html`。

## 调性

**深寂 depth · 流动 flow · 碎金 glint**

没有地平线，没有船，没有任何可以做参照的东西。整个画面就是一片起伏的水——深蓝的波谷占了绝大多数面积，低角度的光从侧面掠过来，只在浪脊上留下一道道金色的碎光。这是纯粹的光与纹理，没有叙事，没有主体，也没有方向。

坐标：温暖 2.6/10 · 安静 8.4/10 · 有机 9.2/10 · 抽象 8.6/10 · 低沉 8/10

五条翻译：
1. **冷底，暖点** —— 四分之三面积是蓝，金色只出现在波峰，总量 ≤15%
2. **低调，强对比** —— 整体明度低，但最深与最亮跨度大；只留「暗蓝」和「亮金」两级
3. **无地平线** —— 不做上下分区，改用漂浮的锚点定位
4. **一切皆为曲线** —— 不存在直线与直角，分隔、进度、图表全用波浪弧线
5. **永远在动** —— 背景波纹始终保持极缓慢流动，静止画面在这套语言里不存在

## 用色规则

四种画布：
- **暗画布（默认）**：底 `#0A1B2C` / `#16324F`，字 `#F0E9DA`，对比 13.2:1
- **浮层画布**：卡片 `#17324E`，靠明度差分层次而非描边
- **照片画布**：先叠 35% 深渊蓝并压暗一档，文字落在深蓝波谷上
- **浅画布（备用）**：底 `#F0E9DA`，字 `#16324F`，强调仍用碎金（对比会变弱，需目检）

六条硬约束：
1. 金色总量 ≤15%，它是「碎光」不是「主色」
2. 金光只落在峰上——单点、细线、小面积，不给整个面涂金
3. 碎金上的文字用深渊蓝（9.4:1），不用深海蓝（4.1:1 偏弱）
4. 两级明度，收窄中间调；均匀灰阶会让画面变浑
5. 不用纯黑，最暗 `#040D16`
6. 两块冷色相接时垫 1px 雾蓝细线，否则糊成一片

对比度：正文 ≥ 4.5:1（雾蓝在深海蓝上只有 3.4:1，只能做注解）· 细体大标题实际按 4:1 执行

## 字体

**默认方向 · 现代冷峻**：中文 思源黑体 Light / 苹方细体；英文 Inter Light / Helvetica Neue Thin
**可替换 · 古典辽阔**：标题用 Cormorant / Didot / 思源宋体 Light；正文仍用无衬线

核心是**用轻字重、大字号、宽字距**——深色底上的细字有通透感，粗字显得笨重。

1920×1080 基准下：

| 层级 | 字号 | 字重 | 字距 | 行距 |
|---|---|---|---|---|
| 主标题 Display | 110–160px | 200 | +4% | 1.12 |
| 章节标题 H1 | 64–80px | 300 | +4% | 1.20 |
| 二级标题 H2 | 40–48px | 300 | +3% | 1.35 |
| 正文 Body | 26–30px | 300 | +2% | 1.85 |
| 数据数字 Metric | 130–220px | 300 | +2% | 1.00 |
| 注解 Caption | 18–20px | 400 | +8% | 1.60 |

字重只用 200 / 300 / 400；需要强调时提高字号或改成金色，不加粗。
一行中文 ≤ 16 字；正文左对齐；数字全部等宽。

## 版式

- 12 列网格，列间距 = 列宽 1/2，外边距 = 画面宽 **10%**（比常规更宽）
- 间距全部是 8 的倍数：8 / 16 / 24 / 40 / 64 / 96 / 144
- **16:9**：安全区 80%×80%；不做上下分区，改左右分置，中间由一条横贯波浪连接；标题落在纵向 30%–45%
- **9:16**：上 18% 与下 8% 留给平台 UI；核心信息在纵向 32%–78%；波浪减到 1 条
- **无地平线处理**：不加页头页脚这类横带结构，靠留白和明度分层次
- 圆角极小：卡片 4px、小元素 2px。这是「水面」不是「有机体」，直角偏冷更配深底
- 阴影换成发光：`0 0 40px rgba(212,174,114,.14)`，模拟碎光扩散
- 描边 0.5–1px，颜色 `rgba(212,174,114,.18)` 或 `rgba(143,165,184,.16)`，两端渐隐

## 形态母题（所有图形只从这六个来）

| 母题 | 用途 | 参数 |
|---|---|---|
| 波纹线 | 分隔线、进度条、时间轴、层级 | 波长 24–48px，振幅 6–12px，stroke 1–1.6px；多条时上亮下暗 |
| 浪脊 | 峰值标注、关键转折 | 峰高 = 基线 3–5 倍，尖端点径 3px |
| 碎金斑 | 数据点、粒子、噪点、疏密表强度 | 直径 1.6/2.5/3.2px，不等距排列 |
| 镜面带 | 基准线、高亮区、章节分隔 | 1–2px，两端渐隐 30%，不用实心色条 |
| 涟漪环 | 聚焦、点击反馈、同心层级 | 椭圆比 1:0.37，环间距递减 30% |
| 深浅层 | 数据分层、堆叠面积、多序列 | 层间明度差 ≥12%，相位对齐，4–6 层 |

材质：镜面垂直渐变幅度 ≤10% · 4–6% 噪点 · 远景水层模糊 6–14px · 图标 stroke 1–1.5px 且优先用波纹与涟漪变体

## 动效

核心不是入场动画，而是**背景永远在动**。

| 用途 | 动作 | 时长 | 缓动 |
|---|---|---|---|
| 背景波纹 | 匀速横向位移一个波长，无限循环 | 16–24s | linear |
| 元素入场 | 上移 20px + 淡入 | 800–1200ms | cubic-bezier(.22,1,.36,1) |
| 光泽扫过 | 金色渐变沿曲线从一端移到另一端 | 1400–2000ms | cubic-bezier(.45,0,.55,1) |
| 涟漪扩散 | 同心椭圆由中心向外扩散淡出 | 900ms | ease-out |
| 数据增长 | 数值与波形同步，一条曲线画到底 | 1200–1800ms | ease-out |
| 章节转场 | 横向波纹推移扫过整屏 | 1000ms | cubic-bezier(.4,0,.2,1) |

规则：慢一个数量级 · 连续不断 · 多层用 0.4/0.7/1.0 视差速度比 · 只做位移与透明度（不缩放不旋转）· 金色光泽只扫一次

## 图文搭配

- 照片先叠 35% 深渊蓝并降一档亮度再压字
- 文字避开金色高光区，落在深蓝波谷上
- 满版铺图可用到总页数 1/3（图本身是抽象纹理，无具象主体）
- 单屏文字 ≤30 字
- 统一调色：曝光 -0.3、对比 +10、高光 -14、阴影 -8、色温 -6、蓝色饱和 +8
- 不用方框、不用带投影的卡片、不用直角图标、不用纯色实心按钮
