# 晨光牧场 · 视觉色彩规范 v1

> 取自 studiofriluma-cow-10441555。用于视频与演示文稿的配色、字体、版式、图形与动效标准。
> 完整可视化版本见 `design-spec.html`。

## 调性

**晨光 lit · 生长 alive · 温润 warm**

一头棕色奶牛在清晨的草地上吃草，侧逆光把草叶和野花照得近乎透明，前景的黄色毛茛被虚化成光斑，远处的云杉林沉在阴影里压住重心。真实、有重量的自然——不是「可爱农场」的甜腻。

坐标：温暖 8/10 · 安静 7/10 · 有机 9/10 · 真实 8/10

四条翻译：
1. **暖主导，冷点缀** —— 七成暖色撑情绪，三成冷色（云杉墨绿、天空蓝）给骨架
2. **高饱和，但被柔化** —— 颜色纯度高，但明度抬高、明暗对比压低
3. **肌理真实，结构抽象** —— 材质保留照片级颗粒，结构必须抽象成几何
4. **大留白，单一焦点** —— 一屏一个重点，其余是空气

## 用色规则

三种画布：
- **亮画布**（默认）：底 `#F7F4EC` + 字 `#2E4736`，对比 9.8:1
- **暗画布**：底 `#2E4736` + 字 `#EFE9DC`，对比 8.6:1
- **照片画布**：照片 + 45% 可可深棕 或 55% 云杉墨绿蒙版 + 米白文字

六条硬约束：
1. 野花黄只做点，面积 ≤ 8%；大面积强调改用牧草绿
2. 黄底不用白字，用可可深棕（对比 7.2:1）
3. 受光黄绿与野花黄之间至少隔一层云杉墨绿或牛棕
4. 不用纯黑纯白，最暗 `#121F17`，最亮 `#FDFBF5`
5. 天空蓝总量 ≤ 5%，它是锚点不是主色
6. 饱和色块相接时加 1px 米白描边或留 12px 空隙

对比度：正文 ≥ 4.5:1 · 大标题 ≥ 3:1 · 关键信息不单靠颜色区分

## 字体

- **中文** 标题 思源宋体 / 方正风雅宋；正文 思源黑体 / 苹方 / 微软雅黑
- **英文** 标题 Fraunces / Playfair Display；正文 Inter / Helvetica
- **数字** 等宽数字（tabular figures）

1920×1080 基准下：

| 层级 | 字号 | 字重 | 字距 | 行距 |
|---|---|---|---|---|
| 主标题 Display | 96–140px | 700 | -2% | 1.10 |
| 章节标题 H1 | 64–80px | 600 | -1% | 1.20 |
| 二级标题 H2 | 40–48px | 500 | 0 | 1.30 |
| 正文 Body | 26–30px | 400 | 0 | 1.65 |
| 数据数字 Metric | 120–200px | 700 | -3% | 1.00 |
| 注解 Caption | 18–20px | 400 | +4% | 1.50 |

字重只用 400 / 500 / 700；中文正文不加字距；一行中文 ≤ 20 字，英文 ≤ 45 字符。

## 版式

- 12 列网格，列间距 = 列宽 1/3，外边距 = 画面宽 8%
- 间距全部是 8 的倍数：8 / 16 / 24 / 40 / 64 / 96
- **16:9**：安全区 84%×84%；标题左上，数据居中偏下，标识右下
- **9:16**：上 18% 与下 8% 留给平台 UI；核心信息在纵向 30%–75%
- 照片构图参考：上 1/3 天空作呼吸口，信息放下方 2/3
- 圆角：卡片 24px，小元素 12px，按钮全圆；不用直角
- 阴影：`0 8px 40px rgba(46,71,54,.12)`，单层、柔和、带绿味

## 形态母题（所有图形只从这六个来）

| 母题 | 用途 | 参数 |
|---|---|---|
| 草叶弧线 | 分隔线、进度条、坐标轴、下划线 | stroke 2–3px，曲率半径 ≥200px，圆头 |
| 花点 | 数据点、列表符、粒子、时间轴节点 | 直径 6/10/16px，间距不规则 |
| 云杉三角 | 并列、阶梯、增长、层级 | 底:高 = 1:2.2，顶角圆角 2px |
| 奶牛斑块 | 卡片背景、图片蒙版、强调底衬 | 转角半径 ≥ 高度 30%，无锐角 |
| 光晕 | 聚焦、强调、气氛底 | 半径 ≥160px，中心不透明度 ≤25% |
| 地平线 | 版式分区、图表基准线、转场 | 1px，当前底色明度偏移 12% |

材质：3–5% 胶片噪点 · 两级景深（辅助元素 blur 8–20px）· 高光偏暖、阴影偏绿，不用中性灰
图标：线性 stroke 2px，圆头，单色，强调时只染一个局部

## 动效

节奏慢，靠呼吸感而非弹跳。

| 用途 | 动作 | 时长 | 缓动 |
|---|---|---|---|
| 入场 | 上移 16px + 淡入 | 400–600ms | cubic-bezier(.16,1,.3,1) |
| 强调 | 缩放 1.00→1.03 + 亮度 +8% | 300ms | ease-out |
| 退出 | 淡出 + 轻微上移 | 250ms | ease-in |
| 章节转场 | 柔焦进出 blur 0→20→0 | 700ms | ease-in-out |
| 数据增长 | 数值与图形同步 | 800–1200ms | ease-out |

同屏元素依次入场间隔 80–120ms；转场用清晰→模糊→清晰；关键帧至少停 1.2 秒。

## 图文搭配

- 照片作底叠 45% 可可深棕 或 55% 云杉墨绿蒙版
- 裁切保留地平线，不裁天空
- 单张照片最多压 2 行字
- 满图页 ≤ 总页数 1/4
- 统一调色：曝光 +0.3、对比 -12、色温 +8、绿色相偏黄
- 不用白描边剪贴画、渐变图标、带投影的 3D 字
