# 叙事结构：独立成片怎么"讲故事"

透明素材是**贴片**（一块一块的强调），独立成片是**完整内容**（从头到尾自己扛）。
差别不在长度，在**连贯性** —— 每一屏都要回答"上一屏说了什么、这一屏推进到哪"。

---

## 一、三幕骨架

一部片子至少要有这三段，缺一段就会"散"：

| 幕 | 作用 | 时长占比 | A/B |
|---|---|---|---|
| **开场（open）** | 立住问题 / 抛出结论 | ~15% | 只用 A（标题大字） |
| **主体（body）** | 展开论证，2~5 个意群 | ~70% | A + B 同屏 |
| **收尾（close）** | 收束成一句可记住的话 | ~15% | 只用 A（引述 / 金句） |

```
开场         主体 · 意群1        主体 · 意群2        主体 · 意群3      收尾
┌────┐   ┌──────────────┐   ┌──────────────┐   ┌──────────────┐   ┌────┐
│ 主张│ → │ 主张 + 证据   │ → │ 主张 + 证据   │ → │ 主张 + 证据   │ → │ 金句│
└────┘   └──────────────┘   └──────────────┘   └──────────────┘   └────┘
```

**每个意群内部**都是一个 A+B 单元：A 说要什么，B 拿数据/图表证明。
意群之间要有"推进"——时间线（去年→今年）、层次（一线→三线）、因果（因为→所以）。

---

## 二、A-roll / B-roll 分规划

**A-roll = 主张**，**B-roll = 证据**。这两条轨道要**分别规划**，不能混着写。

| | A-roll | B-roll |
|---|---|---|
| 承担什么 | 这一屏的**观点** | 支撑观点的**事实** |
| 形态 | 标题大字 / 生成素材 | 数据卡 / 柱 / 线 / 环 / 清单 / 对照 |
| 落点 | 上半带（`data-roll="A"`） | 下半带（`data-roll="B"`） |
| 用词 | 短句、结论式 | 名词 + 数字，不带修饰 |
| 入场 | 先出 | 晚 0.4~0.8s |

**规划顺序**：

1. 先把整片的 **A-roll 串起来** —— 只看 A 能不能读出完整逻辑链？
   把每个 A 抄下来连成一段话，如果读得通，说明骨架立住了。
2. 再给每个 A 配 **B-roll** —— 哪个 A 需要证据？（不是每个都要）
3. 开场和收尾**只留 A** —— 一头一尾不需要证据，需要的是方向和记忆点。

> **自检法**：遮住所有 B-roll 只看 A-roll，逻辑不断 → 骨架合格。
> 遮住 A-roll 只看 B-roll，只有数据没有结论 → 正常（B 本来就是配角）。

---

## 三、密度

| 指标 | 参考值 |
|---|---|
| 每幕停留 | **5~8s** |
| 组件密度 | **每 8~12 秒 2~3 个** |
| 3 分钟片子 | **25~40 个**组件 |
| 一屏同场组件 | **最多 A+B 两条**（三个以上会乱） |

**不要塞太满。** 信息密度过高的后果是观众什么都记不住。
一屏只讲一件事，讲完换下一屏。

---

## 四、连贯的四个手法

独立成片的"连贯感"是设计出来的，不是自然发生的。四个手法：

### 1. 视觉锚点延续

上一屏的某个元素（一个色块、一个数字、一条线）在下一屏**换个位置继续存在**。
最简单的做法：让 B-roll 的柱子颜色沿用意群的主色。

### 2. 数字接续

这一屏的结论数字，就是下一屏的起点。
"增速 37%" → 下一屏"这 37% 里，54% 来自三线"。

### 3. 提问 / 回答

A-roll 抛问题，下一屏的 A-roll 给答案。
**但不要滥用** —— 一个问题就够，连着问会累。

### 4. 收尾回扣开场

收尾的金句要**回扣开场的问题**。
开场立"渠道下沉带来结构性增长"，收尾就该是"增量不是抢来的，是长出来的"。

---

## 五、与透明素材的区别（别搞混）

| | 独立成片 | 透明素材 |
|---|---|---|
| 形态 | 整屏，自己扛叙事 | 3:4 一块板，贴到别人视频上 |
| 连贯 | **必须连贯**，A→B 有推进 | **不需要连贯**，块间留空档 |
| 密度 | 密集（每 8~12s 2~3 个） | 稀疏（60s 8~12 个） |
| 对脚本 | 每句都要响应 | 只对章节 / 概念 / 数据 / 图像响应 |
| 归属技能 | `ivh-standalone` | `ivh-overlay` |

**两者的文本结构完全不同，不要用同一套写法。**

---

## 六、自检

- [ ] 遮住 B-roll 只看 A-roll，逻辑链完整
- [ ] 每个意群内部是"主张 + 证据"，不是纯罗列
- [ ] 开场 / 收尾都只用 A-roll
- [ ] 收尾回扣了开场的问题
- [ ] 每幕停留 5~8s，一屏最多 2 个组件
- [ ] 全片组件总数在 25~40 之间（3 分钟）
- [ ] 组件样式换着用，没有一路 `c-data`
- [ ] 全片至少 3 种入场动效
