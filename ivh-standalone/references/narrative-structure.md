# 叙事结构：独立成片怎么"讲故事"

独立成片是**完整内容**（从头到尾自己扛）。差别不在长度，在**连贯性** ——
每一屏都要回答"上一屏说了什么、这一屏推进到哪"。

---

## 一、骨架

```
开场         主体 · 意群1        主体 · 意群2        主体 · 意群3      收尾
┌────┐   ┌──────────────┐   ┌──────────────┐   ┌──────────────┐   ┌────┐
│ 主张│ → │ 主张 + 证据   │ → │ 主张 + 证据   │ → │ 主张 + 证据   │ → │ 金句│
└────┘   └──────────────┘   └──────────────┘   └──────────────┘   └────┘
```

**每个意群内部**是一个 A+B 单元：A 说要什么，B 拿数据 / 图表证明。
意群之间要有"推进" —— 时间线（去年→今年）、层次（一线→三线）、因果（因为→所以）。

三类 `role` 的时长占比与密度数值见 SKILL 的三幕表。

---

## 二、A-roll / B-roll 怎么分开规划

**这两条轨道分别规划，不能混着写。** 规划顺序：

1. 先把整片的 **A-roll 串起来** —— 只看 A 能不能读出完整逻辑链？
   把每个 A 抄下来连成一段话，读得通就说明骨架立住了。
2. 再给每个 A 配 **B-roll** —— 哪个 A 需要证据？（不是每个都要）
3. 开场和收尾**只留 A** —— 一头一尾不需要证据，需要的是方向和记忆点。

> **自检法**：遮住所有 B-roll 只看 A-roll，逻辑不断 → 骨架合格。
> 遮住 A-roll 只看 B-roll，只有数据没有结论 → 正常（B 本来就是配角）。

一屏同场组件**最多 A+B 两条** —— 一屏只讲一件事，讲完换下一屏。

---

## 三、连贯的四个手法

独立成片的"连贯感"是设计出来的，不是自然发生的：

### 1. 视觉锚点延续

上一屏的某个元素（一个色块、一个数字、一条线）在下一屏**换个位置继续存在**。
最简单的做法：让 B-roll 的柱子颜色沿用意群的主色。

### 2. 数字接续

这一屏的结论数字，就是下一屏的起点。
"增速 37%" → 下一屏"这 37% 里，54% 来自三线"。

### 3. 提问 / 回答

A-roll 抛问题，下一屏的 A-roll 给答案。
**一个问题就够**，连着问会累。

### 4. 收尾回扣开场

收尾的金句要**回扣开场的问题**。
开场立"渠道下沉带来结构性增长"，收尾就该是"增量不是抢来的，是长出来的"。
