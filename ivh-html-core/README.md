# ivh-html-core —— HTML 产物阶段的共享层

**这不是一个 Skill。** 本目录**没有 `SKILL.md`**，所以不会被宿主当成技能加载。
它是 ②③④ 三个技能共用的**产物契约与词汇表**，靠相对路径被引用。

```
ivh-standalone/  ─┐
ivh-overlay/     ─┼─→  ../ivh-html-core/…
ivh-render/      ─┘
```

## 里面是什么

| 文件 | 用途 | 谁读 |
|---|---|---|
| `interop.md` | **产物契约**：合成根 `data-*`、运行时名字（`TL` / `curScene` / `.in`）、截图定位、透明输出、HUD 三件套、两支线产物形态差异 | ②③④ |
| `components.md` | **词汇表**：组件元素契约 + 状态机、15 种组件（`c-*`）与用法示例、13 入场 / 4 退场动效、多样性硬线、停留时长 | ②③ |
| `visual-styles.md` | 六风格完整规格（变量层 / 结构层 / 动画层） | ②③ |

## 为什么要有这一层

唯一的共享面只能有一个物理副本 —— 同名文件各存一份必然漂移
（`interop.md` 曾长成三个版本，`components.md` 两份额外重复约 150 行）。

- 想改契约、改组件名、改动效名 → **改这里**，②③④ 同时生效。
  ⚠️ 改组件名 / 动效名**还必须同步改两个技能各自的 `assets/template.html` 运行时**：
  对不上不会报错，只是那块板不动。
- 想改某条支线自己的结构（分幕 / A-B 分带 / 素材点规模）→ 改那条支线的 `references/`。

## 引用方式

各技能的 `SKILL.md` 与 `references/` 用 `../ivh-html-core/…` 引；
两个技能的产物模板 `assets/template.html` 注释里也用同一路径。

> **安装提示**：`ivh-*-core` 必须与其余技能放在同一个父目录下 —— 靠 `../` 相对引用。
> 安装脚本见仓库根 `README.md`。
