# 提炼法：从原文到屏幕字

**共享层文档。** 讲「怎么把一段话压成一句话」；压出来的字该长什么样见 `text-layers.md`。
压缩链两支线共用，落点不同：`standalone` 落在幕标题，`overlay` 落在素材点。**§四的钩子与金句只对 `standalone` 成立。**

## 一、判据

评价脚本只看两件事：

| | 判据 |
|---|---|
| **概括度** | 只看全部屏幕字、按顺序读，读出来是一段**论证**还是一份**目录** |
| **爆发点** | 有没有哪一句让人「咯噔」一下 |

**自查**：把屏幕字摘出来连成一段读 —— 像大纲 = 没提炼；像一段话 = 提炼了。
目录型是默认结果：它对每句话都成立，所以对观众什么也没说。

一个真实反差。原文：

> 只靠一线城市，到明年大概只能覆盖四成用户；把渠道下沉到三四线，会翻到七成以上。

| | 屏幕字 | 读起来 |
|---|---|---|
| 目录型 | 渠道策略 / 市场分析 / 结论 | 一份目录 |
| 提炼后 | **一线 40% → 三四线 70%** | 一句话 |

两版信息量相同，区别只在有没有压缩 —— 目录型的病不在「写太少」，在**没压缩**。

## 二、压缩链：四步

```
原文 / 口播稿
   ↓ ① 抓手     圈出可量化、可对比的东西
   ↓ ② 论点     它们合起来说明什么（一句话，带因果）
   ↓ ③ 主张     这句话的反面成立吗？成立就退回 ②
   ↓ ④ 屏幕字   压到 ≤2 行 × ≤12 字
```

| 步 | 动作 | 过关判据 |
|---|---|---|
| ① 抓手 | 有哪些**数字 / 时间 / 对比 / 代价**？ | 一个都没有 → 先去找数字 |
| ② 论点 | 这些抓手合起来说明什么？ | 别人能听懂「所以呢」 |
| ③ 主张 | **有人会不同意吗？** | 没人反对 = 废话，退回 ② |
| ④ 屏幕字 | 用最少的字摆出主张 | 不写主语、不写连接词，只留对比两端 |

**第 ③ 步是分水岭**：「渠道下沉很重要」没人反对（共识）；「一线见顶，增量全在三四线」有人反对 —— 才是主张。
主张是**要付代价的判断**，没有代价的判断是描述。

完整走一遍。原文：

> 原来以为三四线付费能力不行，不敢往下走。今年数据推翻结论：转化率比一线高 1.8 倍，获客成本只有一半。

| 步 | 结果 |
|---|---|
| ① 抓手 | 转化率 1.8 倍 / 成本 1/2 / 「以为…推翻」 |
| ② 论点 | 三四线的转化与成本都比一线好，与直觉相反 |
| ③ 主张 | **不是付费能力不行，是一直没去试** |
| ④ 屏幕字 | `三四线转化 1.8 倍` / `获客成本 少一半` |

③ 用的是**「不是 A，是 B」**结构 —— 天然带主张，因为它排除了一种说法。

### ① 抓手随 contentType 变

压缩链四步不变，**第 ① 步圈什么取决于 `meta.contentType`**：

| `contentType` | 抓手 |
|---|---|
| `data` | 数字 / 占比 / 趋势 / 对比 |
| `narrative` | 转折 / 代价 / 反差 / 命名 |
| `drama` | 转折 / 冲突 / 身份 / 情绪 |
| `opinion` | 转折 / 反差 / 代价 |

`data` 用「有刻度」当硬检验；其余三种把「有刻度」换成**「有没有反转 / 代价」** ——
「他走了」是描述，「他走了，再没回来」才是转折。

`parse-srt.mjs --content` 必须与 `meta.contentType` 一致：拿数据型规则筛 31 句剧情台词，
候选句 **0 条**，而且不报错。

## 三、主张的四条检验

写不出主张时用这四条筛，一条不过就重写：

| 检验 | 问法 | 不合格 |
|---|---|---|
| **可反驳** | 有人会不同意吗？ | 「渠道很重要」 |
| **有代价** | 换来什么、付出什么？ | 「要重视渠道下沉」 |
| **有刻度** | 有数字 / 时间 / 程度吗？ | 「效果会更好」 |
| **一口气** | 能一口气说完吗？ | 三行以上的长句 |

「有刻度」最好补：找到一个数字，标题立刻从抽象变具体 —— 这也是 `check-script.mjs` 单独报「带数字屏幕字占比」的原因。

## 四、爆发点（`standalone`）

一条片子只需 **1 个钩子 + 1 句金句**，多了等于没有。

### 开场（前三秒）

| 类型 | 句式 | 例 |
|---|---|---|
| 反常识 | 不是 A，是 B | `不是没人买，是没人敢推` |
| 代价 | A 的代价是 B | `省下的渠道费，都赔在了复购上` |
| 反差数字 | X 对 Y | `40% 的天花板` |
| 提问 | 为什么 X 却 Y？ | `为什么越下沉越赚钱？` |

开场要**判断**，不要主持词 —— 「大家好」「今天我们来讲」会被判成空转标题。

### 中段

数字本身不是爆发点，**反差**才是：数字型素材点要带参照，`54%（去年 21%）` 而不是 `54%`。

### 收尾：金句

合格标准：**能脱离这条视频单独发出去**。发片标题、封面文案直接从这里拿。

- ✅ `往下走，才有增量` · `不是没需求，是没在场`
- ❌ `以上就是今天的内容` · `希望对大家有帮助` · `总结一下`

## 五、候选法：一次写 5 个，挑 1 个

每个需要屏幕字的位置先写 **5 个候选**，再挑 1 个：

| 角度 | 例（围绕"下沉市场"） |
|---|---|
| 数字型 | `54% 增量来自三四线` |
| 反差型 | `一线见顶，增量在下沉` |
| 代价型 | `下沉赚到了规模，赔掉了毛利` |
| 提问型 | `为什么越下沉越赚钱？` |
| 名词型 | `下沉市场的第三次机会` |

挑的顺序：**有刻度 > 可反驳 > 短 > 顺口**。第 1 个念头永远最安全（也最平），反差结构在第 4、5 个。

**落盘**：5 个候选 + 为什么选它，写进同名 `.md` 的「候选与选择」小节；`.json` 只放选中的那个。

## 六、对照表：平淡 → 提炼后

| 平淡 | 提炼后 | 差在哪 |
|---|---|---|
| 渠道问题 | 一线见顶，增量在下沉 | 分类名 → 判断 |
| 现状分析 | 54% 的增量来自三四线 | 章节名 → 数字 |
| 提升转化效果 | 转化率 1.8 倍，成本一半 | 补刻度、删口号 |
| 用户画像 | 25~34 岁占 6 成 | 概念 → 分布 |
| 内容概述 | 今年只做了三件事 | 元话语 → 事实 |
| 总结 | 往下走，才有增量 | 流程词 → 金句 |
| 我们要重视这个问题 | 这个问题的代价是复购 | 呼吁 → 代价 |
| 第一部分 | 一线为什么见顶 | 占位符 → 问题 |

规律只有一条：**把「关于什么的」换成「什么」**。

## 七、check-script 会拦什么

`check-script.mjs` 第 7 项查**提炼度的下限**（属"写法"不属"字段"，所以不写在 `script-format.md`）：

| 判据 | 级别 |
|---|---|
| 空转标题（客套 / 结构占位 / 自我指涉） | **FAIL** |
| 屏幕字重复 | **FAIL** |
| body 标题是纯名词短语 | **FAIL** |
| 带数字的屏幕字 < 40% | note |
| 开场标题没有钩子 | note |
| 收尾不像金句 | note |
| 口号式标题（有形容词没数字） | note |
| 素材点只有 1 个元素 | note |

**过校验 ≠ 提炼到位**：真正的判据还是 §一 那条 —— 屏幕字连起来读，像一段话还是像一份目录。
