# 可视化选型与组件映射

**共享层文档。** 脚本里要写 `scenes[].broll.comp` / `points[].comp`，所以两个脚本技能都必须知道下游有哪些组件可用。
这份只列名字、用途、门槛，不管怎么画（那是 ②③ 的事）。

## 一、技术路线

产物是**单文件 HTML、零外部依赖**（校验脚本第 2 项会拦），第三方库必须**内联**。按此排序：

| 优先级 | 路线 | 什么时候用 | 体积代价 |
|---|---|---|---|
| 1（首选） | **纯 CSS + 内联 SVG** | 柱 / 环 / 折线 / 流程 / 对比 —— **九成场景够用** | 0 |
| 2 | 内联 D3 子集（只打包用到的模块） | 真正的坐标轴、力导向、多序列图 | 几十~上百 KB |
| 3 | 内联 Lottie JSON + 轻量播放器 | 已有现成的高质量动效素材（AE 导出） | 通常 >200 KB |

**默认走路线 1**：手写 SVG 比引库更快、更可控，动效也更好对齐时间轴。

升级到 D3 的条件：数据维度 ≥3、需要动态刻度、或要做多序列对比。此时在脚本里标 `viz: "d3"`，并把**数据结构**写全。

Lottie 的动效由自己的时间轴驱动，和外部的 `data-in` 卡不住 —— 只适合独立成片的 A-roll 背景层。

## 二、可选技术标签

脚本里用一个可选字段 `viz` 记录（不加就等于"纯 CSS/SVG"）：

| `viz` | 含义 |
|---|---|
| 省略 | 纯 CSS + 内联 SVG（默认） |
| `d3` | 需要 D3 子集，必须把数据写成 `data.series` 数组 |
| `lottie` | 需要播放 Lottie，必须给 `data.src`（相对路径） |

## 三、组件索引（15 种）

类名一律 `c-` 前缀。`comp` 字段填这里的类名，**只填类名，不写坐标不写样式**。

### 信息卡类 —— 承载一个信息点

| 类名 | 表达什么 | 数据形态 | 适配画幅 |
|---|---|---|---|
| `c-data` | 一个超大数字 + 归因标签 | `to` / `prefix` / `suffix` / `dec` / `k` | 通用 |
| `c-bar` | 横向柱状对比（2~4 条） | `rows[{label, value, color?}]` | 通用 |
| `c-ring` | 环形占比 / 完成度 | `pct` + `cap` | 通用（竖版慎用） |
| `c-line` | 折线趋势 | `series[{x, y}]` 或 `path` | 横版优先 |
| `c-list` | 清单，逐条 | `items[]`，每条 ≤14 字 | 通用 |
| `c-vs` | 一句话级对比 `A ≠ B` | `left` / `right` | 通用 |
| `c-cmp` | 上下两块的数值对照 | `a{label,value}` / `b{label,value}` | **竖版原生** |
| `c-flow` | 上→下转化（含箭头与关系标签） | `from` / `to` / `relation` | **竖版原生** |
| `c-stack` | 竖向递进（三块 + 序号） | `layers[{no, text}]`，≤3 层 | **竖版原生** |

### 文字类 —— 承载主张或语气

| 类名 | 表达什么 | 字数上限 |
|---|---|---|
| `c-kw` | 关键词大字，无容器 | ≤8 字 |
| `c-quote` | 引述 / 金句，竖线 + 斜体 | ≤24 字 |
| `c-rule` | 强调下划线，短句高亮 | ≤14 字 |
| `c-note` | 便签，补充信息 | ≤30 字 |

### 导航类 —— 告诉观众"讲到哪了"

| 类名 | 表达什么 | 字数上限 |
|---|---|---|
| `c-capsule` | 胶囊标签，短归因 | **≤6 字** |
| `c-step` | 步骤编号 | ≤8 字 |

## 四、怎么选

按**口播在说什么**倒推：

| 口播信号 | 选谁 |
|---|---|
| "增长了 37%" / "达到 1.2 亿" | `c-data` |
| "A 比 B 高" / "其中三线占一半" | `c-bar` |
| "完成了六成" / "覆盖率 62%" | `c-ring` |
| "从 2023 到 2026 一路走高" | `c-line`（`viz: d3` 若要多序列） |
| "三个原因：第一…第二…第三…" | `c-list` 或 `c-stack`（竖向递进） |
| "不是 A，是 B" | `c-vs`（一句话）或 `c-cmp`（带数值） |
| "从 A 变成 B" | `c-flow` |
| "所谓 X，就是…" | `c-kw` + `c-note` |
| 金句 / 结论 | `c-quote` |
| "第一部分" / "接下来" | `c-capsule` |

**组件换着用**：每 3 个组件至少换 1 种样式，整条片子 2~3 种。
全是 `c-data`（或连着两块 `c-cmp`）会非常单调。

**数字类组件都带参照物**（同比 / 去年值 / 基数），不是孤零零一个百分数。
竖版构图优先 `c-flow` / `c-stack` / `c-cmp` 这三个竖版原生组件。

控件名与 `viz` 的合法性由 `check-script.mjs` 兜底 —— 写错名字会在盖章时被拦下。
