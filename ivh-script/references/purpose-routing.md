# 用途判定：先分水岭，再定密度

`ivh-script` 的第一件事不是写字，是**判断这份脚本最终要变成什么**。
判错了，后面全盘重做 —— 因为两条支线的文本结构完全不同。

## 一、分水岭

| | `purpose = standalone` | `purpose = overlay` |
|---|---|---|
| 它是什么 | 一条**独立的成片** | 一堆**贴到别人画面上的素材** |
| 画面是谁的 | 技能自己的 | 别人的（实拍 / 口播视频） |
| 覆盖范围 | 整屏 | 局部一块板 |
| 连贯性 | **必须连贯**，从头到尾一条叙事 | **不必连贯**，每块独立成立 |
| 要不要响应每一句 | 要，每个意群都要有画面 | **不要**，只挑关键处 |
| 画布 | 四选一（`16:9` / `9:16` / `4:3` / `3:4`） | 恒 `3:4` |
| 背景 | `opaque`（可透明，见下） | 恒 `transparent` |
| 文本结构 | 幕 + A-roll/B-roll 分规划 | 稀疏的素材点 |
| 有没有口播稿 | 通常有（自己配音，或用来对齐剪辑） | 通常没有（贴别人的口播） |

**同一个主题，两种产物完全不同。** 不要试图写一份"两用"的脚本。

## 二、怎么判

按顺序问，第一个命中的就是答案：

1. **用户说"做成视频发出去 / 我要一条成片"** → `standalone`
2. **用户说"叠在我的口播上 / 剪映里贴上去 / 要透明底"** → `overlay`
3. **用户给的是自己的口播稿，且要求"配上画面"** → 若画面要铺满整屏 → `standalone`；
   若只是几处强调 → `overlay`
4. **都没说** → 问。**不要默认。** 这两条支线的返工成本极高。

### 边界情况

| 情形 | 判给谁 | 理由 |
|---|---|---|
| 整屏透明、内容铺满，准备叠在实拍上 | `standalone` + `bg=transparent` | 它要连贯、要响应每一句，只是背景透明而已 |
| 只有 3 个数字要强调，其余留白 | `overlay` | 稀疏，不符合"连贯" |
| 知识科普、无口播 | `standalone` + `base=text` | 整屏、有自己的叙事节奏 |
| 用户自己会剪，只要素材 | `overlay` | 剪的决定权在用户手上 |

> **"整屏透明叠加"不是第三种产物。** 它是 `standalone` 把 `bg` 换成 `transparent`。
> 判据始终是**连贯 vs 稀疏**，不是透明与否。

## 三、密度：两条支线的核心差异

### `standalone` —— 密集、连贯

- 每一幕 **5~8 秒**，幕与幕首尾相接、不留缝
- 全片组件总量参考：**每 10 秒 1~2 个**（3 分钟片 ≈ 20~35 个）
- 一屏之内可以同时有 A-roll（主张）与 B-roll（证据）
- 开场必须有 hook，收尾必须能独立成为一句话
- 节奏靠**组件交叠**制造，不靠硬切
- 60 秒的片子：约 8~12 幕

### `overlay` —— 稀疏、独立

- 只对四类地方做呼应：**章节切换 / 关键概念 / 图像 / 表格数据**
- 一个素材点停留 **≥0.8s**，理想 **2.5~4.5s**
- 相邻点之间留 **≥1.5s 纯透明空档** —— 连续铺满会让叠加层变成"第二块屏"
- **60 秒口播 → 8~12 个素材点**。少于 5 个偏漏，多于 14 个偏挤
- 同一时刻**只有一组元素**，不做多个组件共存
- 不做开场、不做收尾 —— 素材没有"起承转合"

> 一句话记：**`standalone` 是填空，`overlay` 是点缀。**

## 四、锁五维

脚本的 `meta` 里要把下游要用的五维一次锁死，别让下游再猜：

| 维度 | `standalone` | `overlay` | 谁定 |
|---|---|---|---|
| `purpose` | `standalone` | `overlay` | **脚本直接写死** |
| `ratio` | 四选一 | `3:4` | 脚本写死 |
| `bg` | `opaque` / `transparent` | `transparent` | 脚本写死 |
| `style` | 六选一 | 六选一 | **必须在此刻定**，下游不许改 |
| `base` | 不写（下游按有无时间码自决） | 不写（恒 `timeline`） | —— |

**风格为什么必须在脚本阶段定？** 因为风格决定文字长度上限：
`neon` 的字号比 `minimal` 大、容字更少。写完脚本再换风格，得回头重写字。

默认风格：口播 / 数据类 → `minimal`；科普 / 讲解类 → `doodle`；
技术 / 系统类 → `blueprint`；潮流 / 品牌类 → `neon` 或 `riso`。

## 五、自检

- [ ] `purpose` 是问出来的或用户明说的，不是我猜的
- [ ] 两条支线没有混写（`scenes` 与 `points` 只有一个非空）
- [ ] `standalone`：幕区间首尾相接，覆盖全片
- [ ] `standalone`：`role` 三类齐全，开场有 hook，收尾可独立成句
- [ ] `overlay`：每 60s 落在 8~12 个素材点，空档 ≥1.5s
- [ ] 五维已在 `meta` 里锁死，`style` 已定
