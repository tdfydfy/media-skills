# 幕：独立成片的结构单元

**本支线专有。** 独立成片的形态是"填空"：一屏一个主张，从头铺到尾，不留洞。

---

## 一、一幕由什么组成

```json
{
  "i": 1,
  "role": "open",
  "start": 0.0,
  "end": 6.4,
  "aroll": {
    "type": "title",
    "kicker": "2026 · 市场观察",
    "text": "渠道下沉\n带来结构性增长",
    "emphasis": "结构性"
  },
  "broll": { "comp": "c-data", "note": "留白，先不给数字" },
  "anim": "MASK-UP"
}
```

| 层 | 给谁 | 约束 | 落点 |
|---|---|---|---|
| A-roll | 眼睛（主张） | 一行最大字 | `aroll` |
| B-roll | 眼睛（证据） | 组件 ≤1 个/幕为宜 | `broll` |
| 口播 | 耳朵 | 15~40 字/句 | `voiceover[]` |

**A-roll 与 B-roll 是"主张 vs 证据"的分工**，两层各自可以单独占一屏，
一屏之内同时出现也是允许的 —— 这正是独立成片的密度来源。

---

## 二、`role` 三类的气质

| `role` | 在片子里干什么 | 标题该长什么样 | 反例 |
|---|---|---|---|
| `open` | 前三秒决定观众走不走 | 悬念 / 主张 / 一个反常识的判断 | "大家好，今天我们来讲渠道下沉" |
| `body` | 推进论证 | 一个具体结论，带数字或对比 | "第一，渠道问题" |
| `close` | 收束成一句话 | 能**脱离这条视频单独发出去** | "以上就是今天的内容" |

三类各至少一个。开场的四种句式与金句标准见 `../../ivh-script-core/distillation.md` §四。

---

## 三、A-roll：三种来源

| `aroll.type` | 是什么 | 依赖 | 额外字段 |
|---|---|---|---|
| `title` | 排版标题，屏幕上最大的一行字 | **零依赖**，默认选它 | `text` / `kicker` / `emphasis` |
| `gen-image` | 生成一张图当背景 / 主体 | 需要下游生成 | `prompt` / `src` / `genStatus` |
| `gen-video` | 生成一段视频 | 需要下游生成 | 同上 |

`meta.aRollSource` 记录全片主用哪种：`title` / `gen` / `mixed`。
`gen-*` 的落地由 `ivh-standalone` 负责：脚本先写 `genStatus:"pending"` 与 `prompt`，
下游生成完回写 `src` 并置 `genStatus:"done"`。

### 标题的硬约束

| 约束 | 值 | 理由 |
|---|---|---|
| 行数 | **≤2 行** | 3 行的标题会被观众当成正文去读 |
| 每行字数 | **≤12 字** | 超过就换行，换不了就砍字 |
| `emphasis` | 至多 **1 个词** | 强调两处等于没强调 |
| `kicker` | ≤10 字，可选 | 标时间 / 章节 / 出处，不要拿它当第二句标题 |

`text` 里用 `\n` 手动换行。**换行位置就是视觉断句**，别指望下游替你断。

## 四、节奏

- **承接感来自衔接，不来自重叠。** 两幕的 `end` 与下一幕的 `start` 必须相等。
- **节奏靠组件交叠制造**，不靠硬切 —— 上一幕的组件还没退完，下一幕的字已经进来。
- 全片只有一个钩子、一句金句。**多了等于没有。**
- 组件别一个用到死：每 3 个组件至少换 1 种样式（全是 `c-data` 会非常单调）。

---

## 五、常见错误

| 症状 | 病因 | 修法 |
|---|---|---|
| 幕之间有黑场 / 跳帧 | 区间有洞或重叠 | 让相邻幕 `end == start` |
| 标题写了 3 行 | 当成正文写了 | 压到 2 行 × 12 字 |
| 标题念出来就是口播那半句 | 复述，不是概括 | 标题给结论，口播给推理 |
| 强调词标了 3 个 | 想强调的太多 | 只留 1 个 |
| 收尾是"以上就是今天的内容" | 流程词占位 | 换成能单独发的金句 |
| 中间几幕全是 `c-data` | 组件单调 | 换 `c-flow` / `c-cmp` / `c-quote` |
| `gen-*` 写了但没给 `prompt` | 下游没法生成 | 补齐 `prompt`，`genStatus:"pending"` |
| 末幕 `end` 与 `totalDuration` 不等 | 时长算错 | 对齐到音轨末句的 `end` |
